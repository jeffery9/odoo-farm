# 史诗 27：农业循环经济与废弃物资源化 (Circular Economy)
*目标：建立内部资源循环闭环，实现废弃物向投入品的价值转化。*

1. **[US-27-01] 粪污/秸秆资源化登记**：🚧 正在进行 (2026-01-14)
    - **描述**：作为环保专员，我希望记录养殖废弃物或秸秆的收储与发酵过程。
    - **验收条件**：
        - 必须包含“发酵腐熟度”质检点（US-15-01 联动）。
        - 记录必须自动关联至对应地块的“养分归还”台账。

2. **[US-27-02] 内部转化投入品换算**：🚧 正在进行 (2026-01-14)
    - **描述**：作为农业技术员，我希望系统将发酵后的有机肥折算为可用的养分库存。
    - **验收条件**：
        - **(Logic)** 自动按 NPK 成分比例，抵扣后续种植季的化肥采购需求。
        - 转化过程必须通过 `mrp.production` 实现（废弃物为原料，有机肥为成品）。

3. **[US-27-03] 危险废弃物（药瓶/地膜）合规处置**：✅ 已完成 (2026-01-25)
    - **描述**：作为合规专员，我希望记录农药包装等危险废弃物的回收流向，满足环保审计。
    - **验收条件**：
        - 系统必须维护“危废转移联单”，记录交接人、重量及接收主体。
        - 报表必须支持一键导出符合监管要求的“危废处置台账”。

4. **[US-27-04] 沼气/生物质能转化量化**：✅ 已完成 (2026-01-25)
    - **描述**：作为农场主，我希望计算废弃物转化产生的能源价值，提升 ESG 表现。
    - **验收条件**：
        - **(Logic)** 每一笔发酵任务自动根据产气系数折算为“标准煤替代量”。
        - 数据自动推送至碳足迹账本（Epic 30）。
