# 史诗 25：通用现场证据存证系统 (Generic Field Evidence)
*目标：将现场影像采集与业务对象深度绑定，通过地理水印与哈希校验实现全方位的合规背书。*

1. **[US-25-01] 万物皆可取证**：✅ 已完成 (2026-01-14)
    - **描述**：作为农场工人，我希望在巡田发现异常时能随时拍摄照片并关联至对应的任务 or 地块。
    - **验收条件**：
        - 提供通用的照片采集接口，支持关联至任意 Odoo 模型。
        - **(PWA)** 拍摄过程必须支持完全离线，照片自动暂存于本地 IndexedDB 队列。

2. **[US-25-02] 自动化地理水印**：✅ 已完成 (2026-01-14)
    - **描述**：作为质量管理员，我希望导出的证据照片上自动叠加拍摄时的环境信息。
    - **验收条件**：
        - 系统采集硬件坐标并在 Evidence 记录中持久化。
        - 水印包含：经纬度、采集人全名、服务器同步时间。

3. **[US-25-03] 空间证据合规审计**：✅ 已完成 (2026-01-14)
    - **描述**：作为审计员，我希望系统自动标记那些在作业区域外拍摄的证据。
    - **验收条件**：
        - **(Logic)** 系统对比地块边界，自动更新证据的“位置合规”状态（红/绿标识）。

4. **[US-25-04] 证据看板展示**：✅ 已完成 (2026-01-14)
    - **描述**：作为农场主，我希望通过看板视图快速浏览全场的影像现状。
    - **验收条件**：
        - 提供缩略图预览（Thumbnail Preview）功能。

5. **[US-25-05] 证据链哈希校验 (Core-Closure)**：✅ 已完成 (2026-01-14)
    - **描述**：作为审计员，我希望校验同步后数据的原始性。
    - **验收条件**：
        - **(Logic)** 采集瞬间生成 Hash 摘要。
        - 同步后系统自动比对，检测数据是否曾被后期篡改。
