# 史诗 20：数据交换与标准化 (Data Exchange & Standardization)
*目标：确保系统符合中国农业数据交换规范，实现标准化数据目录与接口管理。*

1. **[US-20-01] 农业数据资源目录管理**：✅ 已完成 (2026-01-14)
    - **描述**：作为数据管理员，我希望系统按照国家标准管理数据资源目录，支持分类与元数据维护。
    - **验收条件**：
        - 所有的核心数据表（如地块、批次、干预）必须关联对应的“元数据标签”。
        - **(Logic)** 数据结构必须通过 JSON Schema 验证，确保 100% 符合 NY/T 3984-2021 追溯数据接口规范。

2. **[US-20-02] 数据交换接口标准化**：✅ 已完成 (2026-01-14)
    - **描述**：作为技术员，我希望系统提供标准化的数据交换接口，便于与政府或第三方平台对接。
    - **验收条件**：
        - 系统必须对外提供符合 Restful API 标准的接口文档（Swagger/OpenAPI）。
        - 物联网数据采集必须适配 NY/T 2970-2016 规范中的字段命名。

3. **[US-20-03] 数据质量与一致性校验**：✅ 已完成 (2026-01-14)
    - **描述**：作为质量管理员，我希望系统能够自动校验数据质量，防止耳标号等关键数据冲突。
    - **验收条件**：
        - 系统必须提供“数据质量报告”，定期扫描并列出“缺失关键属性”的记录。
        - 必须包含“重复值检测”逻辑（如：重复的耳标号、证照号）。

4. **[US-20-04] 数据共享与权限控制**：✅ 已完成 (2026-01-14)
    - **描述**：作为管理员，我希望控制数据的共享范围，确保公开数据的脱敏安全性。
    - **验收条件**：
        - **(Security)** 必须支持“数据脱敏”导出：针对公开接口，自动隐藏手机号、身份证号等隐私。
        - 所有的外部 API 调用必须记录完整的访问日志（调用者 IP、时间、结果）。
        - 符合双语描述标准。

5. **[US-20-05] ISO 11783 (ISOBUS) 农机作业数据集成**：✅ 已完成 (2026-01-25)
    - **描述**：作为机务主管，我希望直接导入符合 ISOBUS 标准的农机作业 ISO-XML 文件，自动生成地块作业日志。
    - **验收条件**：
        - **(Logic) **建立符合国际标准的任务控制器（Task Controller）报文解析器。
        - **(Odoo Mapping) **解析结果必须能自动关联至对应的 `mrp.production` 记录。

6. **[US-20-06] UN/CEFACT 电子农业追溯报文交换**：✅ 已完成 (2026-01-25)
    - **描述**：作为国际供应链专员，我希望根据联合国 UN/CEFACT 标准与国际买家交换标准化的追溯电子单证。
    - **验收条件**：
        - **(Logic) **支持导出符合 EPCIS 规范的电子追溯事件报文。
        - 报文内容必须涵盖从地块、投入品到运输的全过程双语存证数据。
        - 必须支持 GS1 全球统一资产编码体系。
