# 史诗 94：中药材与炮制管理 (Medicinal Herbs & TCM Processing)
*目标：建立符合 GMP 规范的中药材生产体系，管理道地性指标与复杂的炮制加工工艺。*

## 1. 用户故事 (User Stories)

1. **[US-94-01] "道地性"环境因子验证 (Authenticity Environmental Factor Verification)**：💡 待规划
    - **描述**：作为质检经理（Quality Manager），我希望记录地块的特殊环境数据（如有效成分积聚期的特定温差），以证明药材的"道地"身份。
    - **验收条件**：
        - **(Logic)** 必须建立"有效成分预测模型"，基于 IoT 历史数据自动计算该批次的"预估药效成分含量"。
        - 对外溯源页必须展示"道地性背书 / Terroir Verification"证书。

2. **[US-94-02] 规范化炮制工艺控制 (Standardized Processing Control)**：💡 待规划
    - **描述**：作为工厂主管（Factory Manager），我希望对中药材的净制、切制、炮制（如：醋炙、酒炙）进行严格的过程记录。
    - **验收条件**：
        - **(Hard-Block)** 关键步骤（如：蒸制时长）必须作为 `mrp.production` 的必填质检点。
        - 炮制过程中使用的"辅料（如：特定比例的米醋、黄酒）"必须通过 `mrp.bom` 精准扣减库存。
        - 生成的批次合格证必须标注"炮制规格 / Processing Specification"。

## 业务价值
- **核心价值**: 建立符合 GMP 规范的中药材生产体系，管理道地性指标与复杂的炮制加工工艺
- **目标用户**: 质检经理、工厂主管
- **量化收益**: 通过道地性验证确保中药材符合道地性要求和品质标准，符合GMP和中医药相关法规要求，实现炮制工艺的标准化管理，建立完整的中药材质量追溯体系

## 技术挑战
- **复杂性**: 需要处理道地性验证、炮制工艺控制、成分分析等复杂中药材加工技术
- **性能要求**: 成分预测和工艺控制需高效准确
- **安全合规**: 需要符合GMP规范、中医药法规、数据安全等多重法规要求
- **集成难点**: 与IoT设备、MRP系统、质检系统、追溯系统等多系统的集成
