# 史诗 32：品牌价值、地理标志与有机诚信体系 (Brand, GI & Organic)
*目标：通过风土数字化、防伪认证及诚信评分，提升农产品溢价并捍卫品牌声誉。*

1. **[US-32-01] 产地风土数字化 (Terroir Profiling)**：✅ 已完成 (2026-01-14)
    - **描述**：作为农业技术员，我希望记录地块的微气候、坡度、水源及土壤矿物质，为品牌故事提供科学背书。
    - **验收条件**：
        - 地块模型（stock.location）必须包含自定义风土字段组。
        - 属性数据必须支持导出为面向客户的双语“风土报告”。

2. **[US-32-02] 地理标志 (GI) 防伪集成**：✅ 已完成 (2026-01-14)
    - **描述**：作为仓库管理员，我希望系统自动在出库标签上打印符合国家地理标志保护规则的唯一防伪序列号。
    - **验收条件**：
        - 系统必须维护 `agri.gi.registry`。
        - **(Branding)** 标签打印必须支持调用第三方防伪 API 获取唯一编码。

3. **[US-32-03] 品牌渠道保护白名单**：✅ 已完成 (2026-01-14)
    - **描述**：作为营销经理，我希望设置特定高溢价批次仅能销往指定的精品渠道。
    - **验收条件**：
        - **(Logic)** 当尝试为非白名单客户确认包含此类批次的 SO 时，系统必须拦截并提示错误。

4. **[US-32-04] 有机诚信实时评分 (Integrity Scoring)**：✅ 已完成 (2026-01-14)
    - **描述**：作为审计员，我希望基于生产全过程自动生成地块诚信分数。
    - **验收条件**：
        - **(Logic)** 评分公式：诚信分 = 地理围栏合规率 * 0.4 + 投入品白名单率 * 0.4 + 检测合格率 * 0.2。
        - 分数低于 60 分时，系统必须自动向质检主管发送“降级预警”Activity。

5. **[US-32-05] 品牌+风土动态展示页**：✅ 已完成 (2026-01-14)
    - **描述**：作为消费者，我通过扫码可以看到包含风土图片、实时气温和有机证书的精美品牌页面。
    - **验收条件**：
        - **(Branding)** 页面风格必须符合品牌视觉规范，支持动态视频加载。
        - 所有技术指标必须提供双语解读。

6. **[US-32-06] 外部审计员“远程透明化”查验门户**：✅ 已完成 (2026-01-25)
    - **描述**：为减少认证机构现场检查频次，我希望为第三方审计员开通受限的查验入口，允许其远程调取 IoT 监测历史与作业存证。
    - **验收条件**：
        - **(Security) **实现只读审计角色，仅能访问脱敏后的“合规底账”。
        - 提供“审计一键包”：汇总导出特定认证周期内的所有关键控制点凭证。

7. **[US-32-07] 生态缓冲区多样性监控与展示**：✅ 已完成 (2026-01-25)
    - **描述**：作为品牌经理，我希望量化展示有机地块周边的生态隔离带（如益虫引诱带）现状，作为品牌生态价值的背书。
    - **验收条件**：
        - **(GIS) **在地图上独立渲染隔离带（Buffer Zone）及其维护日志。
        - 溯源页支持动态展示隔离带内的生物多样性实拍影像。

## 业务价值
- **核心价值**: 实现品牌价值、地理标志与有机诚信体系，提升品牌信任度和市场竞争力
- **目标用户**: 品牌经理、认证专员、质量管理、消费者
- **量化收益**: 提升品牌溢价20-40%，增强消费者信任，提高市场认可度

## 技术挑战
- **复杂性**: 需要整合地理信息、认证和品牌数据
- **性能要求**: 认证和溯源查询需快速响应
- **安全合规**: 需要符合有机认证和地理标志法规要求
- **集成难点**: 与溯源、质量、认证等系统的集成
