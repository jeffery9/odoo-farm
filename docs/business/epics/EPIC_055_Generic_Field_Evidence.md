# EPIC 055:通用现场证据存证系统 (Generic Field Evidence)
*目标：将现场影像采集与业务对象深度绑定，通过地理水印与哈希校验实现全方位的合规背书。*

1. **[US-055-01] 万物皆可取证**：✅ 已完成 (2026-01-14)
    - **描述**：作为农场工人，我希望在巡田发现异常时能随时拍摄照片并关联至对应的任务 or 地块。
    - **验收条件**：
        - 提供通用的照片采集接口，支持关联至任意 Odoo 模型。
        - **(PWA)** 拍摄过程必须支持完全离线，照片自动暂存于本地 IndexedDB 队列。

2. **[US-055-02] 自动化地理水印**：✅ 已完成 (2026-01-14)
    - **描述**：作为质量管理员，我希望导出的证据照片上自动叠加拍摄时的环境信息。
    - **验收条件**：
        - 系统采集硬件坐标并在 Evidence 记录中持久化。
        - 水印包含：经纬度、采集人全名、服务器同步时间。

3. **[US-055-03] 空间证据合规审计**：✅ 已完成 (2026-01-14)
    - **描述**：作为审计员，我希望系统自动标记那些在作业区域外拍摄的证据。
    - **验收条件**：
        - **(Logic)** 系统对比地块边界，自动更新证据的“位置合规”状态（红/绿标识）。

4. **[US-055-04] 证据看板展示**：✅ 已完成 (2026-01-14)
    - **描述**：作为农场主，我希望通过看板视图快速浏览全场的影像现状。
    - **验收条件**：
        - 提供缩略图预览（Thumbnail Preview）功能。

5. **[US-055-05] 证据链哈希校验 (Core-Closure)**：✅ 已完成 (2026-01-14)
    - **描述**：作为审计员，我希望校验同步后数据的原始性。
    - **验收条件**：
        - **(Logic)** 采集瞬间生成 Hash 摘要。
        - 同步后系统自动比对，检测数据是否曾被后期篡改。

## 业务价值
- **核心价值**: 实现通用现场证据存证系统，保障农业操作的可追溯性和真实性
- **目标用户**: 技术员、质量管理员、审计员、合规人员
- **量化收益**: 提高证据可信度95%以上，支持审计合规，增强溯源能力

## 技术挑战
- **复杂性**: 需要处理多种证据类型和格式的统一管理
- **性能要求**: 图像处理和哈希计算需高效准确
- **安全合规**: 证据数据需具备防篡改能力，符合审计要求
- **集成难点**: 与其他业务系统和移动端的无缝集成
