# 史诗 8：精准营销与客户参与 (Marketing & Engagement)
*目标：连接终端需求，通过溯源故事与订阅模型提升品牌价值与客户粘性。*

1. **[US-08-01] 溯源营销 (Farm to Table)**：✅ 已完成 (2026-01-14)
    - **描述**：作为营销经理，我希望溯源二维码向客户展示完整的生长故事与农场环境。
    - **验收条件**：
        - **(Branding)** 溯源门户必须支持“中英双语 / Dual-language”显示.
        - 页面必须包含该批次的动态环境曲线（来自 IoT 历史数据）。
        - 必须集成“直播按钮”，支持一键跳转至该地块的实时视频流（US-21-03 联动）。

2. **[US-08-02] 订阅制农业 (CSA)**：✅ 已完成 (2026-01-14)
    - **描述**：作为农场主，我希望向客户提供“季节性蔬菜包”订阅，实现自动化的配送安排。
    - **验收条件**：
        - **(Odoo Mapping)** 必须通过 `sale.order.line` 的循环开票（Subscription）功能实现。
        - 系统根据订户选择的频率，自动生成 `stock.picking`（出库单），并按周/月汇总采收预测。

3. **[US-08-03] 社区与忠诚度管理**：✅ 已完成 (2026-01-14)
    - **描述**：作为农场主，我希望建立会员积分体系，增强客户粘性。
    - **验收条件**：
        - 积分规则必须支持自定义配置（如：消费 1 元积 1 分）。
        - 客户门户（Portal）必须展示实时的积分余额及可兑换礼品清单。
        - 所有的忠诚度通知邮件必须采用“中英双语 / Dual-language”格式。

4. **[US-08-04] 全球化"多时区/多语言"溯源门户**：✅ 已完成 (2026-01-25)
    - **描述**：作为品牌经理，我希望溯源门户能根据访客地理位置自动切换语言（中/英/法/日）和时区，展示本地化品牌故事。
    - **验收条件**：
        - **(UI) **门户界面支持不少于 4 种主流国际语言。
        - **(Data) **所有生产节点（采收、质检、装运）自动根据访客本地时区进行时间轴对齐。

5. **[US-08-05] 国际有机认证一键验真**：✅ 已完成 (2026-01-25)
    - **描述**：作为国际消费者，我希望扫码一键跳转至国际认证机构查验农场有机证书的实时真伪。
    - **验收条件**：
        - **(Logic) **集成 Ecocert 等国际机构官网 API 或爬虫。
        - 结果展示必须包含证书有效期、覆盖范围及颁证机构双语介绍。
        - 具备国际级消费者知情权公信力 UI 组件。

## 业务价值
- **核心价值**: 通过精准营销和溯源体系建设，提升品牌信任度和客户参与度
- **目标用户**: 营销经理、农场主、品牌经理、消费者
- **量化收益**: 提升品牌溢价15-25%，增加客户留存率，扩大市场份额

## 技术挑战
- **复杂性**: 需要整合溯源、营销、认证等多个系统的数据
- **性能要求**: 溯源门户需快速响应，认证查询需实时返回
- **安全合规**: 需要保障用户数据和认证信息的安全性
- **集成难点**: 与第三方认证机构API和直播平台的集成
