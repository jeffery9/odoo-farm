# EPIC 131: 新型蛋白与生物转化农业 (Alternative Proteins & Bio-conversion)
*目标：通过昆虫养殖（如黑水虻 BSF）和微藻培养，将传统的农业废弃物高效转化为高价值的新型蛋白和油脂，构建工业级别的生物制造流水线。*

### **[US-131-01] 黑水虻 (BSF) 生物转化全生命周期管理**
- **描述**: 作为生物工厂厂长，我希望追踪从虫卵孵化、幼虫养殖、到成虫羽化和产卵的立体循环全生命周期。
    *   **验收标准 (Acceptance Criteria)**:
        *   **AC1 (微气候控制)**: 养殖车间的温湿度/二氧化碳必须与 IoT 模块强绑定，支持阶段式环境曲线下发。
        *   **AC2 (生命周期流转)**: 虫卵、幼虫、预蛹、成虫必须使用不同的物料编码，阶段之间的转化（如：幼虫 -> 预蛹）必须支持基于生命周期的自动过账。
        *   **AC3 (损耗预警)**: 若特定批次的幼虫存活率（基于图像识别生物量评估）低于阈值，自动触发环境检查工单。

### **[US-131-02] 动态有机废弃物混合配方 (Dynamic Waste Formulation)**
- **描述**: 作为饲料配方师，我希望根据接收到的厨余或农业废弃物的含水量和营养成分，动态调整喂养黑水虻的投料配方。
    *   **验收标准 (Acceptance Criteria)**:
        *   **AC1 (配方自适应)**: 当废弃物批次的含水率变化时，系统自动反向计算需要添加的干辅料（如麦麸）数量。
        *   **AC2 (生物转化率 KPI)**: 每个投喂批次完工时，自动计算并记录 生物转化率 (FCR: 投入废弃物干重 vs 产出幼虫干重)。
        *   **AC3 (合规隔离)**: 严格区分厨余垃圾与合规农业废料，系统必须阻止受限废弃物投入用于人类食品级新型蛋白的生产批次。

### **[US-131-03] 光生物反应器微藻培养控制 (Microalgae Photobioreactor Control)**
- **描述**: 作为微藻工程师，我希望精准控制管式光生物反应器 (PBR) 内的光照度、溶氧和 pH 值，实现微藻的连续采收。
    *   **验收标准 (Acceptance Criteria)**:
        *   **AC1 (连续制造支持)**: MRP 引擎必须支持“连续流”生产模式，无需频繁启停生产单即可记录每日抽取的藻液产出。
        *   **AC2 (精密控制互锁)**: IoT 探针检测到 pH 值偏离时，自动向执行器下发电磁阀开合指令（注入 CO2），并生成机器干预日志。
        *   **AC3 (生长曲线模型)**: 必须集成藻类比生长速率 (Specific Growth Rate) 模型，辅助预测次日的采收量。

### **[US-131-04] 新型蛋白深加工与成分萃取追踪 (Extraction Processing)**
- **描述**: 作为深加工主管，我希望记录昆虫或微藻的压榨、萃取过程，管理产出的蛋白粉和油脂。
    *   **验收标准 (Acceptance Criteria)**:
        *   **AC1 (多重联产品)**: 萃取工单必须支持复杂的联合产出设定（例如：压榨 100kg 黑水虻幼虫 = 30kg 昆虫油 + 65kg 虫体蛋白饼 + 5kg 损耗）。
        *   **AC2 (批次继承)**: 产出的终端蛋白/油脂批次，必须能沿着树状结构回溯至最初食用的那批农业废弃物。
        *   **AC3 (质量检测卡点)**: 最终产品在放行销售前，必须通过“重金属及病原微生物”强制质检点 (Quality Gate)。
