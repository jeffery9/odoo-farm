# EPIC 039:用户体验与术语去工业化 (Agri-UX & De-industrialization)
*目标：通过术语映射与表单重构，将 Odoo 工业化 UI 转化为符合农业直觉的极简交互界面。*

## 1. 用户故事 (User Stories)

1. **[US-039-01] 术语农业化深度映射 (Deep Term Mapping)**：✅ 已完成 (2026-01-31)
    - **描述**：作为农场主，我希望系统中的菜单和按钮使用农业术语而非工业术语。
    - **验收条件**：
        - **(Odoo Mapping)** 必须建立 `term.mapping` 数据库，支持根据用户选择的“行业家族”动态切换菜单翻译。
        - **(Interception-Engine)** 实现后端 `ViewInterceptor`：在视图加载阶段，自动检测并替换所有“工厂类”Labels。
        - 导出的 Excel 和 PDF 报表表头自动应用映射后的农业术语。

2. **[US-039-02] 行业化表单布局**：✅ 已完成 (2026-01-14)
    - **描述**：作为技术员，我希望根据不同的活动类型（如酿酒 vs 种植）看到定制化的表单界面。
    - **验收条件**：
        - 系统必须提供“视图模板（View Template）”配置。
        - 种植表单必须包含 GIS 位置快照和 NPK 进度条。
        - 加工表单必须包含能耗读数录入区。

3. **[US-039-03]视觉化状态标识**：✅ 已完成 (2026-01-14)
    - **描述**：作为工人，我希望通过颜色和图标快速识别任务状态与风险。
    - **验收条件**：
        - **(UX)** 遵循“三色信号灯”原则：红色代表预警/拦截，橙色代表即将到期/转换期，绿色代表安全/完成。
        - 移动端卡片视图必须包含至少两个关键指标的视觉化 Badge（如：剩余休药期、积温百分比）。

4. **[US-039-04] 个性化工作空间定制**：✅ 已完成 (2026-01-14)
    - **描述**：作为技术员，我希望能够自定义我的工作台界面，以便于快速访问最常用的农业功能和数据。
    - **验收条件**：
        - 用户可按需订阅“今日干预任务”、“环境监测地图”或“销售汇总”小部件。
        - 配置必须跨设备同步。

5. **[US-039-05] 智能上下文帮助**：✅ 已完成 (2026-01-14)
    - **描述**：作为新入职的农场工人，我希望在执行任务时能够获得实时的操作指导。
    - **验收条件**：
        - 每个复杂表单右上角必须有关联至 `farm.knowledge` 的帮助按钮。
        - 帮助内容必须支持双语显示。

6. **[US-039-07] 多感官交互体验**：✅ 已完成 (2026-01-14)
    - **描述**：作为长期从事农业工作的用户，我希望系统能够支持多种交互方式。
    - **验收条件**：
        - 文本字段必须提供“麦克风”图标，调用浏览器原生语音识别进行文字转写。
        - 关键操作必须提供触觉反馈（震动）。

7. **[US-039-09] 无障碍设计与包容性**：✅ 已完成 (2026-01-14)
    - **描述**：作为有特殊需求的农业从业者，我希望系统能够提供无障碍访问功能。
    - **验收条件**：
        - 系统必须支持“大字模式”，确保视力不佳的从业者亦能准确操作。
        - 所有的 SVG 图标必须包含 `aria-label` 描述。

8. **[US-039-11] 农业 Chatter 增强分组**：✅ 已完成 (2026-01-14)
    - **描述**：作为农场主，我希望 Chatter 中的消息能按“活动”、“字段变更”、“农业事件”进行逻辑分组。
    - **验收条件**：
        - **(Logic)** 消息流支持按类型分类展示（Activities, Field Changes, Agri Events）。
        - 支持分类折叠与过滤。

9. **[US-039-12] 行业上下文快捷切换**：✅ 已完成 (2026-01-14)
    - **描述**：作为多业态农场经理，我希望在侧边栏通过快捷开关切换不同的农业行业上下文（如种植、养殖、加工）。
    - **验收条件**：
        - **(UI)** 侧边栏提供 Industry Context 切换器。
        - 切换后即时应用对应的 `term.mapping` 与视图模板。

10. **[US-039-13] 农业企业级首页 (Dashboard)**：✅ 已完成 (2026-01-14)
    - **描述**：作为场长，我希望有一个集成了天气预警、今日任务、审批统计和实时地图的综合仪表盘。
    - **验收条件**：
        - **(Pivot)** Dashboard 必须包含天气状态、待办统计及 GIS 地图层。
        - 支持跨设备同步订阅的小部件（Widgets）。

11. **[US-039-14] 农业专用图标系统**：✅ 已完成 (2026-01-14)
    - **描述**：作为工人，我希望表单和列表视图中使用专业的农业图标。
    - **验收条件**：
        - **(UX)** 系统集成 FontAwesome 4.7.0 中的农业相关图标集。
        - 所有的图标必须具备无障碍 ARIA 标签。

12. **[US-039-15] 农事任务“一键批量完工” (Batch Closure)**：✅ 已完成 (2026-01-25)
    - **描述**：作为生产经理，我希望能在地图或列表上一键关闭选中的所有日常干预任务。
    - **验收条件**：
        - **(Logic)** 提供 `agri.task.batch.close.wizard` 支持批量反填执行人与日期。
        - 支持在 `farm.task` 与 `project.task` 的列表视图中绑定执行。

13. **[US-039-16] 极简“状态滑块”交互 (Gesture Switch)**：✅ 已完成 (2026-01-25)
    - **描述**：作为工人，我希望通过滑动卡片来切换任务状态。
    - **验收条件**：
        - **(UX)** 集成 `agri_kanban_gesture.esm.js` 监听左右滑动手势。
        - 触发状态变更时伴随触觉反馈（震动）。

14. **[US-039-17] “红绿灯”式巨型极简确认控件 (Traffic-Light Controls)**：✅ 已完成 (2026-01-25)
    - **描述**：在执行田间动作时，我希望表单底部显示巨型彩色按钮，确保即使戴手套也能准确点击。
    - **验收条件**：
        - **(UX)** 采用高饱和度对比色按钮，并集成“长按确认”防误触逻辑。
        - 按钮大小与间距优化，适配工业级防摔手机/PDA。

15. **[US-039-18] 户外“强光模式”一键切换 (High-Visibility Mode)**：✅ 已完成 (2026-01-25)
    - **描述**：巡田巡检时，系统支持一键切换到极简黑白高对比度模式，确保屏幕清晰可见。
    - **验收条件**：
        - **(UX)** 全黑背景、纯白文字、加粗边框。支持在 `Farm Hub` 面板中一键切换。

16. **[US-039-19] 字段控件“点选化”适配 (Selection-First UI)**：✅ 已完成 (2026-01-25)
    - **描述**：我要求系统中所有的分类选择（如品种、等级）在移动端必须以“水平滚动芯片（Chips）”展示。
    - **验收条件**：
        - **(UX)** 开发 `agri_selection_chips` 字段组件，支持点选式高亮交互。

17. **[US-039-20] 快捷备注“标签组合” (Tag-based Notes)**：✅ 已完成 (2026-01-25)
    - **描述**：作为工人，我希望通过点击预设标签（如：异响、色淡）组合成备注，而非手动输入文字。
    - **验收条件**：
        - **(Logic)** 提供 `agri_tag_notes` 挂件，关联 `agri.note.tag` 预设标签池。

18. **[US-039-21] 拇指驱动的“底部动作条” (Thumb-Friendly Bar)**：✅ 已完成 (2026-01-25)
    - **描述**：针对大屏手机单手操作困难问题，主要动作按钮从表单顶部下移至屏幕底部固定位置。
    - **验收条件**：
        - **(UX)** 底部动作条采用 Glassmorphism 样式，集成保存/放弃等关键操作。

19. **[US-039-22] 窄屏“卡片式”信息降维 (Mobile Card Simplification)**：✅ 已完成 (2026-01-25)
    - **描述**：在列表视图中，自动将多列宽表转换为简洁业务卡片，只保留最关键的 3 个字段。
    - **验收条件**：
        - **(UX)** 自动隐藏表头与次要列，保持单屏承载 5 条以上记录。

20. **[US-039-24] PDA 工业级硬件交互集成 (PDA Hardware Mapping)**：✅ 已完成 (2026-01-25)
    - **描述**：在使用工业 PDA 时，系统应直接映射物理扫描按键和 F1-F4 快捷键。
    - **验收条件**：
        - **(Logic)** 全局监听 `keydown` 事件，F1-F4 分别映射至帮助、开始、结束与高对比度切换。

21. **[US-039-25] 去工业化表单动态拦截器 (View Interceptor)**：✅ 已完成 (2026-01-31)
    - **描述**：作为开发者，我希望通过通用拦截机制，自动去除不符合农业场景的 Odoo 原生视图元素。
    - **验收条件**：
        - **(Framework)** 开发 `AgriViewMixin`：重写 `fields_view_get` 方法，根据 Industry Context 动态过滤。
        - **(Consistency)** 确保所有继承自 `mrp` 的模型在前端呈现为 `farm.intervention` 风格。

## 业务价值
- **核心价值**: 消除农业从业者的认知障碍，通过“术语物理隔离”提升系统易用性与操作效率。
- **量化收益**: 提升操作效率 40%，降低培训成本 60%。
