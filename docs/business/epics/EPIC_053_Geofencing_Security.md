# EPIC 053:地理围栏与资产边界安全 (Geofencing & Boundary Security)
*目标：通过虚拟地理边界，实现移动资产的安全监控与作业范围硬约束。*

1. **[US-053-01] 虚拟围栏规划 (Virtual Fence Design)**：✅ 已完成 (2026-01-14)
    - **描述**：作为农场主，我希望在地块 GIS 地图上绘制多边形，定义放牧、禁飞或隔离区。
    - **验收条件**：
        - 支持在地块视图中定义围栏类型。
        - 围栏坐标与地块 GIS 边界自动同步或独立定义。

2. **[US-053-02] 畜禽越界实时告警**：✅ 已完成 (2026-01-14)
    - **描述**：作为技术员，我希望佩戴定位耳标的牛羊脱离围栏时，系统立即发送移动端推送。
    - **验收条件**：
        - **(IOT)** 结合遥测数据，每分钟判定一次坐标是否在多边形内。
        - 越界事件自动记录在资产批次历史中。

3. **[US-053-03] 无人机飞行围栏同步**：✅ 已完成 (2026-01-14)
    - **描述**：作为飞手，我希望导出的 KML 航线文件中自动包含周边禁飞区信息。
    - **验收条件**：
        - **(GIS)** 导出 KML 时，自动合并周边 500 米内的所有禁区围栏。

4. **[US-053-04] 农机作业范围审计**：✅ 已完成 (2026-01-14)
    - **描述**：作为机务主管，我希望审计农机是否在分配的地块内行驶，计算违规面积。
    - **验收条件**：
        - 作业日志支持绘制行驶热力图。
        - 自动统计地块外作业时长，用于外协结算扣减。

5. **[US-053-05] 自动防疫隔离带拦截**：✅ 已完成 (2026-01-14)
    - **描述**：作为安全员，我希望系统在发生疫情瞬间自动生成虚拟隔离带。
    - **验收条件**：
        - **(Hard-Block)** 疫情触发后，周边关联地块自动标记为“警戒区”，禁止其他批次移入。

6. **[US-053-06] 地理围栏告警策略**：✅ 已完成 (2026-01-14)
    - **描述**：作为管理员，我希望设置不同的告警级别（通知、短信或远程制动）。
    - **验收条件**：
        - 关键资产越界支持调用 IoT 指令执行紧急提醒。

7. **[US-053-07] 围栏效力历史报告**：✅ 已完成 (2026-01-14)
    - **描述**：作为质量审计员，我希望查看特定批次在生长全周期内的位置合规证明。
    - **验收条件**：
        - 为“有机放牧”生成“全程在栏”证明报告，支持双语。
        - 联动 OPE 指标（US-37-03）。
