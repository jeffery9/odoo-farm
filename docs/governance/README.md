# ⚖️ 项目治理与维护中心 (Project Governance & Maintenance)

本目录存储 Odoo 农业生态系统的“元规则”，定义了所有开发者与 AI 协作的行为准则与维护流程。

## 1. 核心宪法 (The Constitution)
- **[MAINTENANCE_SPEC.md](./MAINTENANCE_SPEC.md)**: 项目治理最高宪法。定义了 Epic/US 的生命周期、模块规划维护逻辑及 **“无损更新律令”**。

## 2. 执行指南 (Operational Guides)
- **[DEVELOPMENT_CONVENTIONS.md](./DEVELOPMENT_CONVENTIONS.md)**: 开发规范（V1.3）。涵盖 TDD、UI/UX 准则、算法引用标准及 500 行文件上限红线。
- **[CLASSIFICATION_GUIDELINES.md](./CLASSIFICATION_GUIDELINES.md)**: Epic/US 归口分类与精化指南。定义了 **六维价值模型** 与 **ISA-88 执行分层准则**。
- **[DEVELOPER_GUIDE.md](./DEVELOPER_GUIDE.md)**: 开发者总纲。提供从技术栈到底座继承范式的全景视图。

## 3. 系统种子 (Bootstrap)
- **[BOOTSTRAP_PROMPT.txt](./BOOTSTRAP_PROMPT.txt)**: LLM 开发者启动指令备份。确保新进入的 AI Agent 能即刻对齐无损律令。
