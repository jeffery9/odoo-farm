# Odoo Farm 图标设计规范 (Icon Design Spec)

## 1. 视觉语言 (Visual Language)
*   **风格**: 极简扁平化 (Flat Design) + 细线条 (Line Art)。
*   **核心理念**: 专业、现代、直观。移除所有工业冗余感，强调农业自然属性与数字化技术的融合。
*   **格式**: 原生 SVG (支持无限缩放，高性能加载)。

## 2. 色彩体系 (Color Palette)

| 维度 | 色值 (Hex) | 适用场景 |
| :--- | :--- | :--- |
| **Agri-Green** | `#28a745` | 核心生产、基础数据、种植 |
| **IoT-Blue** | `#007bff` | 驾驶舱、自动化、传感器、无人机 |
| **Gold** | `#f1c40f` | 农产品加工、深加工、高溢价产品 |
| **Sky-Blue** | `#3498db` | 生产季规划、计划、任务调度 |
| **Mobile-Teal** | `#1abc9c` | 移动端、现场作业、打卡取证 |
| **Safety-Orange**| `#e74c3c` | 防疫、危机处理、禁飞区、拦截告警 |

## 3. 模块图标定义 (Module Icons)

### [farm_core] 农场基础
*   **设计**: 绿色背景 + 白色线条勾勒的谷仓 (Barn) + 太阳。
*   **隐喻**: 农场的基石，代表万物起源与主数据。

### [farm_dashboard] 经营驾驶舱
*   **设计**: 蓝色背景 + 速度表盘 (Dashboard) + 树叶。
*   **隐喻**: 实时数据驱动决策，动态监控生长速率。

### [farm_processing] 农产品加工
*   **设计**: 金色背景 + 齿轮 (Gear) + 虚线轨迹。
*   **隐喻**: 价值转化与分级，代表农产品向工业制品的蜕变。

### [farm_planning] 生产季规划
*   **设计**: 浅蓝色背景 + 日历 (Calendar) 轮廓 + 顶部挂钩。
*   **隐喻**: 时间维度的管理，强调有序的生产周期。

### [farm_mobile] 移动端作业
*   **设计**: 青色背景 + 智能手机轮廓 + 拍照/打卡加号。
*   **隐喻**: 硬件集成与现场作业，代表触手可及的数字化。

## 4. 顶级菜单 (Top Menu) 建议
对于 Odoo 19 顶层菜单项，建议直接复用关联 Application 模块的 `icon.svg`。
