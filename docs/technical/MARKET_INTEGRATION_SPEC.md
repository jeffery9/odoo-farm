# 市场对接接口规范 (Market Integration Specification)

## 1. 概述
本规范定义了本农场管理系统与外部第三方市场（如电商平台、批发零售商系统、政府产销平台）进行数据交换的标准接口。旨在实现“生产数据资产化”与“产销实时透明”。

## 2. 核心接口定义 (RESTful API)

### 2.1 需求推送到农场 (Push Demand)
*   **端点**: `/api/farm/v1/market/demand`
*   **方法**: `POST`
*   **用途**: 第三方平台向农场发送采购意向或订单。
*   **Payload 示例**:
    ```json
    {
      "external_ref": "MKT-2026-001",
      "product_code": "GREEN_TEA_01",
      "quantity": 500,
      "uom": "kg",
      "target_price": 120.0,
      "delivery_date": "2026-05-20",
      "quality_spec": "Moisture < 7%, Pesticide Residue: ND"
    }
    ```

### 2.2 产出品可用性拉取 (Pull Availability)
*   **端点**: `/api/farm/v1/market/availability`
*   **方法**: `GET`
*   **用途**: 市场拉取农场当前可售库存批次或预计采收批次（基于生物孪生预测）。
*   **响应示例**:
    ```json
    [
      {
        "lot_name": "LOT-2026-TEA-05",
        "expected_harvest": "2026-04-15",
        "predicted_yield": 850,
        "compliance_status": "ready",
        "carbon_intensity": 0.12
      }
    ]
    ```

### 2.3 溯源数据查询 (Traceability Lookup)
*   **端点**: `/api/farm/v1/trace/{lot_name}`
*   **方法**: `GET`
*   **用途**: 第三方零售页面获取全息溯源数据包（JSON 格式）。

## 3. 增强型订购流 (Order Enhancement)

为了提升订购能力，系统需支持以下逻辑：

1.  **预订锁定 (Pre-order Reservation)**: 支持在 `sale.order` 确认前锁定对应的生产批次 (Lot)，防止一货多卖。
2.  **质量规范自动校验 (QC Auto-matching)**: 订单行需强制关联“质量规格书”，系统自动比对批次的 `integrity_score` 与 `residue_limit_ok`。
3.  **动态价格补偿 (Dynamic Adjustment)**: 基于实际采收时的甜度、硬度等指标，自动触发价格加价或减价。

## 4. 安全与认证
*   使用 **OAuth2 / API Key** 认证。
*   支持 **Webhook**：当生产批次状态变为 "Ready for Harvest" 时，自动通知外部市场。
