# 📄 架构白皮书：去工业化精准农业的“干预”体系 (V3.0)

## 1. 核心哲学：去工业化的干预 (The De-industrialized Intervention)
在 Odoo 19 的内核之上，我们通过 `farm_ux` 和 `farm_isl` 彻底剥离了制造业术语。
*   **传统 Odoo**: 制造订单 (MO) -> 生产产品。
*   **本系统**: **干预 (Intervention)** -> 促进生长、转化价值。
“干预”不再是冰冷的工序，而是基于作物生理状态的、具备空间差异化的**生命支持动作**。

## 2. 三层嵌套架构模型 (Three-Layer Nested Model)

### 第一层：业务与合规层 (Level 1 - Operation)
*   **模型**: `mrp.production` (映射为 Intervention)。
*   **职责**: 记录时间、人员、物料成本，满足合规性（谁做的、用了多少药、花了多少钱）。
*   **特性**: 它是所有数据的**锚点**。

### 第二层：科学与决策层 (Level 2 - Science)
*   **模型**: `agri.intervention.vra.prescription` (处方图)。
*   **职责**: 解决“做多少”的问题。它根据 NDVI、生理阶段、品种指纹和环境动力学（如 pH 影响养分吸收率）计算出每一平米土地的最佳剂量。
*   **特性**: **空间差异化 (Spatial Differentiation)**。

### 第三层：精密与物理层 (Level 3 - Precision)
*   **模型**: `farm.operation.order` (基于 ISA-88 标准)。
*   **职责**: 解决“怎么做”的问题。将科学处方转化为物理指令（相位、流量、压力、转速）。
*   **特性**: **实时闭环 (Real-time Closed-loop)**。

## 3. 核心技术创新：VRA 空间动态反馈环 (SD-Loop)
这是本次提升最具突破性的部分。数据在系统内部的流转逻辑如下：

1.  **感知 (Sense)**: 农机 IoT 设备通过 `agri_iot` 上报 GPS 坐标和实时传感数据。
2.  **认知 (Cognize)**: `farm_iot` 拦截坐标，并在 L2 科学层中检索当前网格的处方值。
3.  **计算 (Calculate)**: 根据实时环境因素（如风速、降雨、生理压力）对处方值进行最后一步的**风险对冲修正**。
4.  **执行 (Act)**: 系统自动通过 MQTT 向农机下发 `set_control_point` 指令，农机实时调整喷洒量。

## 4. 商业价值与 ESG 收益
- **增效**: 基于生理阶段的精准施肥，预计提升作物养分吸收率 15-25%。
- **降本**: 结合天气预报的风险对冲（雨前减量），减少了无效投入。
- **合规**: 每一笔 VRA 施用都有完整的“处方依据-执行轨迹-物理反馈”存证，满足极致的 ESG 碳足迹追踪和有机认证要求。
