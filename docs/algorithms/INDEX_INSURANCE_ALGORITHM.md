# 指数保险理赔算法文档 (Index Insurance Payout Algorithm)

## 算法目的
基于气象指数自动触发农业保险理赔，实现快速、客观的保险赔付。

## 输入参数
- `field_id`: 农田ID (int)
- `index_type`: 指数类型（降雨、高温等）(str)
- `threshold`: 触发阈值 (float)
- `duration`: 持续时间要求 (int)
- `weather_data`: 气象站原始数据 (dict)
- `insurance_config`: 保险配置参数 (dict)

## 输出结果
- `payout_trigger`: 理赔触发状态 (bool)
- `payout_amount`: 理赔金额 (float)
- `trigger_data`: 触发数据包 (dict)
- `claim_status`: 理赔状态 (str)

## 算法流程
1. **阈值监控**: 实时监控气象站数据是否达到触发条件
2. **持续时间验证**: 确认异常气象条件持续时间是否满足要求
3. **理赔计算**: 根据指数偏差程度和保额计算理赔金额
4. **自动报案**: 通过 Webhook 向保险公司 API 发送理赔触发数据包
5. **状态更新**: 更新保单理赔状态和相关记录

## 业务规则
- 支持多种气象指数：降雨量、温度、风速等
- 可持续时间要求以避免短暂异常触发
- 结合保额和面积计算精确理赔金额
- 确保气象数据的原始签名和可验证性

## 验证方法
- 与历史灾害数据相关性分析
- 与传统定损理赔结果对比验证
- 第三方气象数据源交叉验证

## 性能指标
- 实时监控响应时间 < 1分钟
- 理赔触发准确率 > 95%
- 支持大规模保单并发监控
