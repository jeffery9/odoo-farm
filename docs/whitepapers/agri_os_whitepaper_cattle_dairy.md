## 2g.1 基础设置与奶牛登记 (Setup & Registration)

智慧奶牛业务基于电子耳标 RFID 唯一标识和严格的近交系数（Inbreeding Coefficient）安全控制。系统通过 `farm_livestock` 模块管理奶牛、系谱台账及圈舍空间定位。

### 2g.1.1 奶牛档案建立与系谱登记业务规程 (Livestock Registration SOP)

*   **建立奶牛个体台账**：
    1.  登录系统，导航至“智慧畜牧 -> 牲畜个体台账”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入或扫描电子耳标 RFID 读取出的全局唯一代码（例如：RFID-982-114092284）。
    3.  输入直观的奶牛名称（例如：黑白花高产奶牛 082 号）。
    4.  选择或输入该牛只所属的“物理圈舍/牛舍”（例如：奶牛二号舍），确保其具备清晰的空间定位。
    5.  点击“保存”，系统会自动创建该牛只的基础电子档案，并将其初始状态设定为“健康”。

*   **登记系谱及近交系数自动校验**：
    1.  导航至“牲畜系谱（Pedigree）”菜单并点击“新建”。
    2.  选择当前的奶牛个体。
    3.  选择或指定该牛只的“父本个体”与“母本个体”。
    4.  点击“保存”。此时，系统底层会自动调起近交系数计算引擎，通过递归系谱树分析，在后台实时计算该杂交组合的理论近交系数（F值）。
    5.  **触发近交安全红线**：若计算得出的近交系数高于严格的 `0.0625`（即十六分之一，代表可能存在严重的近亲衰退风险），系统底层会瞬间触发硬拦截机制，强制抛出“系谱近交系数超标告警”，并在操作屏幕上弹出红色警告框，直接阻断保存动作，彻底防范由于近交衰退引起的奶牛产奶量及免疫力断崖式下跌。

### 2g.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在牲畜个体列表视图下，展示耳标号、奶牛名称、所属圈舍、近交系数、日产奶量以及当前阶段状态。利用 Odoo 19 原生列表行装饰器，数据行将根据状态自适应着色。健康（Healthy）状态以绿色成功样式标记，隔离中（Quarantine）则以黄色警戒样式高亮显示，已出栏（Shipped）显示为置灰只读。
*   **表单视图控制与状态机推进（Form View & State Machine）**：
    表单顶部设计有动作控制按钮和面包屑进度。牛只刚录入时状态为“草稿”。通过状态机引擎（State Machine Engine）将牲畜生命周期迁移至活动健康状态，牛只状态推进为“健康”。
*   **字段只读控制与 Chatter 审计（Read-only Constraints & Chatter Audit）**：
    为了保证生物资产物理属性防篡改，一旦状态推进到“健康”或后续阶段，耳标号、父本、母本及出生日期等核心历史属性将自动变更为只读锁定状态。在“已出栏”阶段，表单内所有字段将永久只读锁定。表单下方的 Odoo Chatter 模块会高频记录每一次体温巡检异常、配种动作及兽医诊疗日志。

## 2g.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

挤奶厅的智能挤奶机器人和通道式自动牛只称重仪，通过高频 Modbus 及 MQTT 工业协议实现遥测数据高频灌入。

### 2g.2.1 智能挤奶机器人数据采集规程 (Milking Robot IoT SOP)

*   **挤奶机器人数据采集上行逻辑**：
    当奶牛佩戴 RFID 电子耳标通过智能挤奶机器人时，机器人网卡自动读取其身份，启动自清洗后开始机械手套管作业。
*   **核心遥测指标解释**：
    1.  **实测挤奶量**：机器人将单次挤出的原奶体积高频写入时序表（升，例如：14.8 升）。
    2.  **乳脂率与乳蛋白率**：挤奶器内置的光学传感器在流动管道中高频测定脂肪和蛋白质，上报至 Odoo（例如：乳脂率 4.15%、乳蛋白率 3.28%）。
    3.  **体细胞计数（SCC）**：用于监测隐性乳房炎的核心健康指标，系统会将此数据实时绑定至该奶牛的时序健康面板上。

### 2g.2.2 挤奶厅高频 MQTT 遥测上行推送 (HTTP IoT Telemetry Payload)

在挤奶完成后，机器人控制电脑会自动向 Odoo 物理接收接口投递传感器名称、时间戳、牛只 RFID、挤奶体积（升）、体细胞计数、乳脂率、乳蛋白率以及挤奶过程中的最大流速（升/分钟）等明文报文。

Odoo 接收到报文后，会利用 mapped 算法直接将产奶量和乳脂乳蛋白指标汇总到对应的原奶批次上。

## 2g.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

乳业安全的底线是防止含有抗生素的原奶或隔离期奶牛的原奶混入奶罐。系统设立了“抗生素检出与健康隔离状态行级排他锁定”网关。

### 2g.3.1 准入控制步骤 (SOP Setup)

1.  **设定状态**：兽医主管在 Odoo 中，将使用特定抗生素治疗的奶牛标记为“隔离（Quarantine）”状态。
2.  **验证拦截**：当挤奶员在 Odoo 创建“原奶入罐单”并点击“验证”时，系统启动自动审核。
3.  **安全判定**：
    *   **绿色状态（无感放行）**：所有提供原奶的牛只均处于“健康”状态。
    *   **红色拦截（行级锁死阻断）**：若有任何一只属于该挤奶批次的奶牛处于“隔离”状态，系统触发强制拦截。

### 2g.3.2 检疫状态严重违规强拦截与物理隔离规程 (GxP Quarantine Gate SOP)

1.  **提交原奶检验**：当质检员提交原奶抗生素化验单或提交挤奶单并点击“验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该批次涉及的全部奶牛档案执行 `SELECT FOR UPDATE NOWAIT` 行级排他锁锁定，阻断任何其他终端并发修改其健康状态。
3.  **自动检索实时健康历史**：
    *   系统检索本挤奶批次中所有牛只的当前健康状态。
4.  **触发红色安全阀硬锁**：
    *   若发现任何一只牛只处于“隔离”状态，系统强制抛出“隔离期牛只原奶违规灌入”安全警告。
    *   异常将直接在挤奶员手持屏幕上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何原奶入罐凭证或加工单。
    *   **设备物理自愈动作**：系统自动向挤奶管道的电磁三通阀发送 0（关闭直通）信号，切断直通主储奶罐的管道，强制将不合规牛奶分流排入废奶收集桶，并启动管道自动反冲洗自愈。

## 2g.4 原奶拼箱与物料谱系溯源 (Harvest & Matter Genealogy)

牧场原奶采收具有典型的 **N:1 拼箱（Blending）**特征（多头奶牛的原奶，汇入同一个大型低温储奶罐 Silo）。

### 2g.4.2 储奶罐拼箱谱系溯源数据报送规程 (Silo Blending Traceability SOP)

*   **储奶罐混合物料核算流程 (Silo Blending Calculation)**：
    当不同奶牛的原奶汇入大型储奶罐时，Odoo 溯源引擎根据挤奶机器人上报的净重，自动执行 N:1 混合物料配平核算。
*   **混合溯源报文明细拆解 (Pedigree Breakdown)**：
    系统自动导出一份混合追溯报文。报文明确指明了目标储奶罐的唯一物料箱码（Target Silo LPN）、产品物理商品类型（例如：高品质低温原奶）、混合日期与时间、以及混合后的总体积。
*   **加权乳品质与碳足迹核算 (Weighted Metrics & Carbon Footprint)**：
    报文精确拆解了每一路源头奶牛的贡献详情：包括牛只耳标号、贡献的分挤奶量、在储奶罐中所占的混合比例、体细胞计数、加权平均乳脂率、加权平均乳蛋白率、以及自动分摊分派的 Scope 1 总生产排碳。上述数据生成后将通过 API 自动加密上报，确保原奶企业能实现全过程、可追溯的高可信绿色合规审计。 Consumers 扫描包装盒二维码即可展现从超市奶瓶 -> 灌装线 -> 储奶罐 -> 挤奶机器人 -> 直至源头黑白花高产奶牛 082 号的完整谱系追溯和健康数据，保证高端乳品信誉。

### 📐 物理数学计算模型：近交系数 (F值) 与原奶干物质校正 (FCM)

Agri-OS 在奶牛和乳业板块中应用以下严格的近交安全与乳质计算模型：

1. **近交系数递归分析 (Wright's Inbreeding Coefficient F)**:
   [ F_X ] = SUM( ( 1 / 2 )^( n1 + n2 + 1 ) * ( 1 + F_A ) )
   *   `n1`, `n2`: 共同祖先 `A` 到父本与母本的系谱世代步数。
   *   `F_A`: 共同祖先 `A` 的近交系数。
   *   ASSERT [ F_X ] < 0.0625 (强制拦截红线，高于 1/16 视为严重近亲，禁止交配并阻断数据库保存)

2. **4% 脂修正产奶量 (Fat-Corrected Milk - FCM)**:
   [ FCM_4% ] = 0.4 * [ Milk_yield (kg) ] + 15.0 * [ Milk_fat_mass (kg) ]
