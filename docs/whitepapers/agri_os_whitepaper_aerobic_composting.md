## 2m.1 基础设置与堆体登记 (Setup & Registration)

固体废弃物好氧堆肥作为农业绿色低碳循环的关键，基于发酵堆体的空间确权管理和严格的高温无害化时窗控制。系统通过 `farm_waste_mgmt` 模块管理堆体资产、好氧堆肥批次及秸秆/畜禽粪便配方。

### 2m.1.1 堆场堆体建立与堆肥周期建立业务规程 (Composting Setup SOP)

*   **建立堆场与堆体物理台账**：
    1.  登录系统，导航至“绿色循环 -> 堆场物理资产”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入唯一的堆体编码（例如：COMPOST-PILE-03）。
    3.  输入直观的堆体名称（例如：一号生态堆场 3 号槽式好氧堆体）。
    4.  在“空间多边形 WKT”文本域中，输入标准的 PostGIS 二维多边形坐标串，界定好氧发酵槽物理空间边界。
    5.  指定堆体的“工艺结构类型（Detailed Type）”，支持：
        *   `槽式好氧发酵 (trough_aerobic)`：利用翻堆机进行机械强制曝气与发酵。
        *   `条垛式堆肥 (windrow_compost)`：林下或大田大体量堆体。
        *   `密闭发酵罐 (closed_reactor)`：全密闭多级立式反应器。
    6.  点击“保存”，系统会自动校验多边形格式。

*   **初始化好氧堆肥周期批次**：
    1.  导航至“好氧堆肥周期”菜单并点击“新建”。
    2.  输入周期批次名称（例如：2026年夏季畜禽粪便与大豆秸秆混合好氧发酵周期）。
    3.  指定使用的“配方/原辅料配比”（detailed_type，例如：鸡粪秸秆高氮碳配方）。
    4.  录入设计的“初始碳氮比（C/N Ratio）”期望（例如：28.5）。
    5.  关联绑定对应的物理堆体。
    6.  点击“保存”，系统流水号发生器会自动在界面顶部生成唯一的堆肥周期号（例如：CTC-2026-0004），并将状态初始化为“草稿”。

### 2m.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在好氧堆肥周期列表视图下，展示堆肥周期号、周期名称、物理堆体、碳氮比、最新实测温度、最新实测含氧量及当前状态。利用 Odoo 19 原生行样式装饰器，数据行将根据状态自适应着色。草稿状态以淡蓝色气泡显示，“发酵升温中（Composting）”状态以绿色成功样式高亮标记，腐熟清槽（Done）状态显示为灰色。
*   **状态机推进与高温期无害化校验（State Machine Progression）**：
    表单顶部设计有动作控制按钮和进度状态。状态机包括“草稿”、“发酵中”、“后熟期”、“已完工”。点击“启动发酵”时，系统验证关联的网格位置，状态推进为“发酵中”。只有当堆体在发酵中累计实测温度超过 55.0°C 达到 15 天（满足国家高温无害化强制合规时窗）后，系统才允许状态推进至“后熟期”。
*   **字段只读控制（Read-only Constraints）**：
    为了保证碳指标及 ESG 审计的严谨，一旦批次进入“发酵中”状态，原辅料配方、堆体空间坐标、碳氮比等核心历史字段将自动变为只读锁定状态。在“已完工”阶段，表单内所有数据字段永久只读锁定。

## 2m.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

堆体内部的温度、含氧量、水分及 pH，通过无线不锈钢插杆式传感器网关（Modbus over RS-485）和自动翻堆机 PLC 变频器执行高频数据遥测与曝气自愈控制。

### 2m.2.1 插杆式传感器数据采集规程 (Composting Probe IoT SOP)

*   **称重传感器高频轮询规程**：
    插入发酵堆体内部的多节式不锈钢探杆，通过低功耗 LoRaWAN 协议高频将堆芯温度、水分、氧气浓度推送至后台时序表。
*   **核心遥测指标解释**：
    1.  **实测堆体核心温度**：网关以寄存器数据读取实测温度值，乘以 `0.1` 缩放因子后，在 Odoo 界面渲染出高精度的摄氏度（例如：62.8°C，温度稳步上升代表好氧微生物发酵旺盛，若异常下降代表需要人工翻堆）。
    2.  **堆内含氧量百分比**：网关读取实测氧气浓度。
    3.  **翻堆机 PLC 自动联动**：当氧气浓度低于 5.0% 且水分处于 60% 危险红线以上时，系统会自动拉起翻堆自愈。

### 2m.2.2 堆肥遥测数据上行推送报文 (HTTP IoT Telemetry Payload)

当环境参数超出安全范围（例如含氧量低于极限且温升停滞）时，探杆网关会自动向系统的 API 推送包含堆体编码、时间戳、物理检测指标：堆体中心温度、堆内含水率、含氧量百分比、可溶性电导率、以及翻堆机工作电流等明文报文。

Odoo 接收到报文后，会将堆内核心温度和氧气时序序列关联至对应的好氧堆肥周期账卡。

## 2m.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

有机肥施用的底线是防止重金属超标、虫卵未灭活或有害病原菌（如大肠菌群）超标。系统设立了“大肠菌群超标自动行级排他锁定”网关。

### 2m.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：质量主管在 Odoo“参数配置”中，设定腐熟有机肥出厂的有害菌最高上限（例如：粪大肠菌群数不得多于 `100 个/g`）。
2.  **验证拦截**：当库管员在 Odoo 创建“有机肥出库单”并点击“验证”时，系统启动自动审核。
3.  **安全判定**：
    *   **绿色状态（无感放行）**：当前实测粪大肠菌群数不多于 `100 个/g` 且重金属抽检合格。系统放行。
    *   **红色拦截（行级锁死阻断）**：若最近一次的检测实测粪大肠菌群数多于 `100 个/g`，系统触发强制拦截。

### 2m.3.2 粪大肠菌群超标强拦截与物理隔离规程 (GxP Composting Gate SOP)

1.  **提交有机肥出库单**：当库管员点击“出库验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该堆肥周期记录执行 `SELECT FOR UPDATE NOWAIT` 行级排他锁锁定，阻止并发修改检疫状态数据，阻断提库单的开具。
3.  **自动检索实时有害菌指标**：
    *   系统检索本堆体关联的所有质检化验日志。
4.  **触发红色安全阀硬锁**：
    *   若不满足安全红线，系统强制抛出“有机肥大肠菌群未灭活超标，含有致病菌危险”安全合规警告。
    *   异常将直接在操作员手持终端上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许出库或转入包装车间的出库调拨单。
    *   **设备物理自愈动作**：系统自动将对应堆体的状态变更为“未腐熟检疫隔离”，向装载机行车变频下发 0 指令（锁定电磁离合器，禁止挖取该堆），并向自动添加翻堆补水阀门下发指令，强制重新引入高热好氧菌剂进行二次高温发酵自愈。

### 2m.4.2 废弃物拼箱发酵谱系溯源数据报送规程 (Composting Blending Traceability SOP)

*   **废弃物原辅料加权平衡计算流程 (Silo Blending Calculation)**：
    当不同地块和禽舍的废弃物汇入好氧发酵槽时，Odoo 溯源引擎根据称重传感器上报的各成分原料净重，自动执行 N:1 混合物料碳氮比配平核算。
*   **混合溯源报文格式明细 (Pedigree Breakdown)**：
    系统自动导出一份混合追溯报文。报文内容包括：目标堆肥槽的物料代号（LPN）、产品物理商品类型（例如：高品质有机肥基质）、混合发酵日期与时间、以及混合后的总重量。
*   **加权发酵指标与 Scope 1 碳汇/减排值分摊 (Weighted Metrics & Scope 1 Allocation)**：
    报文精确拆解了每一路源头原料和牛舍的贡献详情：包括原料批次或牛舍编码、贡献的分重、在发酵堆中所占的混合比例、高温发酵天数、历史堆芯最大温度、以及自动核算折抵的 ESG 废弃物治理减排值（ Scope 1 减排量）。上述数据生成后将通过 API 自动加密上报，确保绿色肥料企业能实现全过程、可追溯的高可信 ESG 绿色合规审计。消费者扫描肥料包装袋上的二维码，即可无缝展现从手持肥料袋 -> 包装罐号 -> 高温灭菌 15 天时间折线 -> 堆芯温度传感器历史曲线 -> 各源头禽舍/秸秆地块，保证绿色生态无污染品质。

## 2m.5 异常排查与常见自愈 (Troubleshooting)

好氧堆肥运行期间，探针插干断裂、发酵温度不升及网络通信故障排除矩阵如下：

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-WST-001** | 插杆式传感器温度值异常偏低低于 30°C | 堆体处于严重缺氧厌氧状态，或探针保护管内部热电阻丝严重受潮断路。 | 手动检查探杆探针；强制启动翻堆机变频器对该堆槽执行强制翻堆曝气自愈。 |
| **ERR-WST-002** | 出库单页面提示 “PATHOGEN_NOT_COMPLIANT” 报错 | 粪大肠菌群数化验超标，事务回滚。 | 锁定堆体发酵状态，强制禁止装载机铲料，并对堆体引入二次好氧菌接种，延长 5 天高温期翻堆自愈。 |
| **ERR-WST-003** | 边缘网关上报 “MODBUS_RS485_NOISE” | 翻堆机变频电机启动时强电磁谐波导致 RS-485 总线高频丢包。 | 在 RS-485 信号线两端并联 120 欧平衡终端电阻，并将信号屏蔽线单端接地。 |

### 📐 物理数学计算模型：堆肥碳氮比 (C:N Ratio) 自动配料与含水调节

Agri-OS 在好氧堆肥和废弃物生态循环中采用以下配料公式：

1. **堆肥初始碳氮比计算公式 (Carbon-to-Nitrogen Ratio)**:
   [ C:N_Ratio ] = ( [ Carbon_mass_1 ] + [ Carbon_mass_2 ] ) / ( [ Nitrogen_mass_1 ] + [ Nitrogen_mass_2 ] )
   [ Carbon_mass_i ] = [ Dry_weight_i ] * [ Carbon_content_i % ]
   [ Nitrogen_mass_i ] = [ Dry_weight_i ] * [ Nitrogen_content_i % ]
   ASSERT 25.0 <= [ C:N_Ratio ] <= 30.0 (黄金配料区间，超限自动计算辅料添加配比)

2. **混合物含水率校正公式**:
   [ Moisture_blend % ] = ( SUM( [ Fresh_weight_i ] * [ Moisture_i % ] ) / SUM( [ Fresh_weight_i ] ) ) * 100
