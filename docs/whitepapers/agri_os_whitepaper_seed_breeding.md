## 2f.1 基础设置与亲本注册 (Setup & Registration)

作物育种与选育业务是农业科技的核心。系统通过 `farm_seed_industry` 模块管理育种原始材料（亲本）、自交与杂交试验批次（试验周期）。

### 2f.1.1 育种亲本建档与试验建立业务规程 (Seed Breeding Setup SOP)

*   **建立育种亲本材料台账**：
    1.  登录系统，导航至“育种管理 -> 亲本档案”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入直观的亲本名称（例如：抗旱高产大豆纯系一号）。
    3.  选择或输入唯一的亲本编码（例如：PARENT-SOY-DRY-01）。
    4.  指定亲本的“生物代次（Filial Generation）”，支持：
        *   `F1 纯系 (f1_pure)`：高纯度自交纯系亲本。
        *   `F2 杂交初代 (f2_hybrid)`：两亲本首次杂交繁育材料。
        *   `Fn 代后续选择 (fn_follow)`：多代自交选择纯化材料。
    5.  设置亲本的“纯度期望值”（例如：99.80%），用于后续世代杂交的理论纯度计算。
    6.  点击“保存”，系统会自动验证该编码在全平台的唯一性，并生成亲本基础档案。

*   **注册自交与杂交试验批次**：
    1.  导航至“育种试验单（Breeding Trials）”菜单，点击“新建”。
    2.  输入试验名称（例如：2026年夏季大豆抗旱自交/杂交试验批次）。
    3.  选择对应的“试验类型”，支持：
        *   `自交纯化 (self_pollinate)`：单亲本套袋自交试验。
        *   `杂交选育 (cross_breed)`：双亲本人工授粉杂交试验。
    4.  指定关联的物理“母本”与“父本”（若是杂交试验，父本必填）。
    5.  关联用于本试验的“育种大田/隔离室”，防止外源花粉污染。
    6.  点击“保存”，系统会自动检索流水号发生器，在界面顶部生成唯一的育种试验单号（例如：TRL-2026-0003），并将状态初始化为“草稿”。

### 2f.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在育种试验单列表视图下，展示试验单号、名称、试验类型、父本、母本、隔离室及当前状态。行数据根据状态进行动态着色：草稿状态以蓝色信息气泡显示，授粉中（Pollinating）状态以绿色成功样式标记。
*   **状态机推进与试验隔离规则（State Machine Progression）**：
    表单顶部设计有动作推进按钮和进度条。试验状态包括“草稿”、“授粉中”、“实验室检测”、“完工放行”。点击“启动授粉试验”，系统会校验隔离地块是否存在外源作物花粉重叠冲突，通过后状态推进为“授粉中”。授粉结束后，点击“进入实验室检测”，状态流转至“实验室检测”。
*   **字段只读控制（Read-only Constraints）**：
    为了保证科研系谱数据的严谨防篡改属性，一旦试验单推进到“授粉中”状态，母本、父本和试验类型将自动变为只读锁定状态。在“完工放行”阶段，表单内所有字段将永久只读锁定，记录同步持久化归档至系谱主库。

## 2f.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

育种授粉期间的环境温湿度、风速和花粉浓度，通过隔离室工业传感器进行高频遥测监控与变频风阀控制。

### 2f.2.1 隔离育种温室环境 PLC 遥测 SOP (IoT Modbus Integration)

*   **PLC 通信网关轮询规程**：
    安装在授粉隔离温室内的物理传感器，通过 Modbus 协议将空气温度、空气湿度、光照及隔离防粉尘风阀阀门状态高频推送至 Odoo 后台时序表。
*   **核心遥测指标解释**：
    1.  **实测温度**：网关以寄存器数据读取实测温度值，乘以 `0.1` 缩放因子后，在 Odoo 界面渲染出高精度的摄氏度（例如 25.6°C）。
    2.  **实测空气湿度**：网关读取实测空气相对湿度值，乘以 `0.1` 在系统界面显示。
    3.  **防粉尘进风阀状态**：监控隔离室进出风口的电子防粉尘气动阀门电磁阀开合，当实测风速或外源花粉浓度过高时，网关自动向 PLC 写入 0（强制关闭风阀），开启纯净内循环，杜绝外源花粉漏入。

### 2f.2.2 隔离室环境参数上行推送报文 (HTTP IoT Telemetry Payload)

当环境参数超出授粉安全温度窗口（例如高于 35°C 会导致花粉失活）时，网关会自动向系统的 API 网口推送状态明文报文。报文内容包括传感器名称（如：授粉隔离温室A栋）、时间戳、MAC地址、信号强度，以及最核心的物理检测指标：室温、相对湿度、过滤后进风风速、紫外线强度以及防粉尘气动风阀的开度百分比。

Odoo 接收到报文后，会将温湿度关联至该隔离室承载的所有育种试验单上，用以累积授粉成功率指数。

## 2c.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

在育种与种子生产中，发芽率（Germination Rate）和基因纯度（Genetic Purity）是种业安全红线。系统设立了“发芽率及纯度实验室检测（GgP 门禁）”硬锁拦截网关。

### 2c.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：生产主管在 Odoo“参数配置”中，设定合规种子入库及销售的法批发芽率放行红线（默认值为 `85.00%`），以及基因高纯度红线（默认值为 `99.00%`）。
2.  **日常检验**：检测员在种子收获后，建立种子实验室质检单，记录实测发芽率及 PCR 基因纯度检测值。
3.  **安全判定**：
    *   **绿色状态（自动放行）**：实测发芽率不低于 `85%` 且纯度不低于 `99%`。系统在后台为该批种子颁发“合格种子放行证（GgP Certificate）”，允许其进入包装及销售调拨环节。
    *   **黄色警戒（人工排查）**：发芽率处于 80% 到 85% 之间，系统发出警告。检测员必须输入“局部发芽迟缓分析”理由，方可继续激活。
    *   **红色拦截（硬锁死阻断）**：若任何指标（发芽率或基因纯度）低于放行红线，系统触发强制拦截网关。

### 2c.3.2 种子纯度不达标强拦截与物理隔离规程 (GxP Germination Gate SOP)

1.  **提交种子质检**：当检测员建立质检表并点击“验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该育种试验记录执行 `FOR UPDATE` 行级锁定，防止并发修改验证数据，阻断库存出库单生成。
3.  **自动检索实时发芽率指标**：
    *   系统检索本试验关联的所有质检单记录。
4.  **触发红色安全阀硬锁**：
    *   若不满足安全红线，系统强制抛出“种子发芽率或基因纯度未达法放红线”安全警告。
    *   异常将直接在检测屏幕上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许出库或转入种子加工包装车间的出库调拨单。
    *   **联动物理设备隔离动作**：系统自动将对应批次种子变更为“不合格检疫隔离”，向隔离冷库门禁下发锁定信号保持关闭，并自动拉起自愈警报，启动物理土地客土净化和排水阻断自愈流程。

## 2f.4 亲本自交系谱与物料双向溯源 (Harvest & Matter Genealogy)

作物种子繁育高度依赖 **双向无环图谱（DAG Lineage）**。每一个新种子批次都是由明确的父本（Male Parent）与母本（Female Parent）通过授粉杂交产生的。

### 2f.4.1 种子系谱双向无环图 (SOP Breed Genealogy DAG Chart)

```text
 [ 原始父本 A ] ──┐
                  ├─► [ 杂交试验 TRL-01 ] ─► 生成子代 [ 试验种子 B ]
 [ 原始母本 B ] ──┘
```

### 2f.4.2 种子系谱溯源数据报送规程 (Genealogy Traceability SOP)

*   **杂交系谱登记流程**：
    当人工授粉完成并结出试验种子时，操作员在手持终端创建采收种子记录单，选择对应的育种试验单，系统会自动记录。
*   **指定母子系谱图谱继承关系**：
    系统在后台通过双向无环图算法（DAG），自动将父本和母本的代码作为“亲本节点”注入到该批种子的系谱结构中。
*   **抗逆性/抗病基因传导逻辑**：
    如果在父本中曾经记录过基因突变（如：高产标记），该标记会自动通过谱系算法，向下无限传导到所有分裂生成的杂交子代种子中，使其自动继承该遗传学优质评级并作为未来进一步杂交的参考。
*   **出厂包装与二维码溯源证书展现**：
    种子在完成包装后，操作员扫描出箱单。系统自动生成该种子批次的唯一身份证二维码标签（张贴在种子编织袋上）。购买者通过手机扫描标签，可直接展现无缝的双向谱系追溯证书：直观展现从零售包装袋 -> 包装罐号 -> 实验室 GgP 检测单 -> 授粉期隔离温室温度 -> 父母本杂交记录 -> 直至最初 F1 纯系祖先亲本的完整历史生长环境、理化检测与无菌操作日志，确保高档种子的科学纯度与品质信誉。

## 2f.5 异常排查与常见自愈 (Troubleshooting)

种子选育期间，隔离阀门卡死、发芽率检测超限及数据包乱序排除矩阵如下：

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-SEED-001** | 隔离温室防粉尘风阀在该关闭时保持开启 | 变频气动执行器电磁阀控制线松动或总线失联。 | 检查气动执行器的供气压力（应在 0.4 到 0.6 bar 之间）；手动测试 PLC 继电器控制线圈。 |
| **ERR-SEED-002** | 种子质检页面提示 “PURITY_NOT_COMPLIANT” 报错 | 种子发芽率低于 85% 或基因纯度低于 99%，事务回滚。 | 锁定地块物料出库，物理隔离当前批次，向地磅放行道闸下发 0（保持关闭）信号，并自动启动物理客土治理。 |
| **ERR-SEED-003** | 边缘网关上报 “MODBUS_TIMEOUT_ALERT” 警告 | 大田传感器网关由于距离过远导致网络上行重传失败。 | 调整温室无线天线方向，必要时在隔离温室顶部架设大功率室外型 LoRa 放大网关。 |

### 📐 物理数学计算模型：种子发芽率 (Germination) 与系谱纯度系数

Agri-OS 在育种试材及繁育体系中使用以下公式：

1. **种子标准发芽率 (Germination Rate)**:
   [ Germination_Rate % ] = ( [ Germinated_seeds_count ] / [ Total_seeds_sown ] ) * 100

2. **杂交系谱纯度系数 (Pedigree Purity Coefficient - PPC)**:
   [ Purity % ] = 1.0 - SUM( [ Variant_plant_count_i ] ) / [ Sample_population_count ] * 100
   ASSERT [ Purity ] >= 99.9% (原种级纯度红线拦截)
