## 2n.1 基础设置与份额代币化预售 (Setup & Registration)

CSA（社区支持农业）业务基于消费者与农场的风险共担机制，通过将地块空间代币化（Tokenization）形成产量代币（Yield Tokens），系统通过 `farm_csa` 模块管理地块资产、预售周期及代币化配方。

### 2n.1.1 地块资产建立与份额预售建立业务规程 (CSA Token Setup SOP)

*   **建立 CSA 物理地块空间台账**：
    1.  登录系统，导航至“社区支持农业 -> CSA 地块资产”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入唯一的物理地块编码（例如：PLOT-CSA-D05）。
    3.  输入直观的地块名称（例如：吉林五常生态有机人参种植地块 CSA 合伙 5 号网格）。
    4.  在“空间多边形 WKT”文本域中，录入标准的 PostGIS 二维多边形坐标，划定合伙人的确权物理边界。
    5.  指定地块代币化“预售等级（Tier）”，支持：
        *   `创始黄金份额 (gold_tier)`：最高规格，拥有优先选品及全套传感器直播特权。
        *   `标准白银份额 (silver_tier)`：常规规格，按比例平摊收获。
        *   `基础青铜份额 (bronze_tier)`：基础规格。
    6.  点击“保存”，系统会自动校验空间格式，初始化地块状态为“预售中”。

*   **初始化份额代币预售周期批次**：
    1.  导航至“CSA 预售周期”菜单并点击“新建”。
    2.  输入预售周期名称（例如：2026年夏季长白山人参 CSA 地块预售周期）。
    3.  指定关联的“产量代币（Yield Token）”类型。
    4.  录入预售设计的“初始发行份额（代币数）”（例如：1000 份）。
    5.  关联绑定物理地块。
    6.  点击“保存”，系统流水号发生器会在表单上方生成唯一的预售周期号（例如：CSB-2026-0005），并将状态初始化为“草稿”。

### 2n.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在 CSA 预售周期列表视图下，展示预售周期号、周期名称、物理地块、发行份额、实售份额、最新库温及当前状态。行数据根据状态动态变色：草稿状态以蓝色信息气泡显示，“预售火爆中（Selling）”状态以绿色成功样式标记。
*   **状态机推进与托管安全阀（State Machine & Escrow Locks）**：
    表单顶部设计有动作控制按钮。状态机包括“草稿”、“预售中”、“大田生长中”、“已提货完工”。点击“发布预售”时，系统验证关联的地 WKT 边界，状态推进为“预售中”。
*   **字段只读控制与 Chatter 审计（Read-only Constraints）**：
    为了保证合伙人资金和系谱数据的严密防篡改，一旦批次推进到“大田生长中”状态，发行总份额、初始单重规格、地块 WKT 坐标将自动变更为只读锁定状态。表单下方的 Chatter 会记录每一次资金转账、多方签名通过日志、以及环境遥测波动。

## 2n.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

合伙地块部署有无线多传感器网关，高频上行空气温湿度、光合有效辐射，并在土壤水分低于设定阈值时执行灌溉电磁阀联动自愈。

### 2n.2.1 CSA 地块温室 PLC 遥测 SOP (IoT Telemetry SOP)

*   **PLC 通信网关轮询规程**：
    安装在合伙温室地块内的温湿度、土壤导电率（EC）传感器，通过 Modbus TCP 协议将数据高频推送至 Odoo 后台时序底座。
*   **核心遥测指标解释**：
    1.  **实测空气温度**：网关以寄存器数据读取实测温度值，乘以 `0.1` 缩放因子后，在 Odoo 界面渲染出高精度的摄氏度（例如：24.2°C）。
    2.  **实测土壤导电率（EC）**：网关读取实测 EC 寄存器值，乘以 `0.01` 显示。
    3.  **滴灌阀电磁阀控制**：网关读取进水主管道滴灌阀门状态。当土壤导电率低于安全红线时，向变频电磁阀下发功率开启信号，自适应调节补水流量。

### 2n.2.2 遥测参数上行推送报文 (HTTP IoT Telemetry Payload)

当环境参数超出安全红线时，边缘网关会自动向系统的 API 推送地块编码、时间戳、物理检测指标：温度、湿度、土壤 EC、光合辐射、以及水阀阀门开度等明文报文。

Odoo 接收到报文后，会将指标自动写入作物生长周期时序记录，用于在合伙人微信小程序端实时展现生长日记。

## 2n.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

在代币化 CSA 交易中，农场需要防止合伙人信用分数过低或款项未足额入账时违规发货。系统设立了“会员信用评级不足自动行级排他锁定”网关。

### 2n.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：出纳主管在 Odoo“参数配置”中，设定允许无感提货的最低信用评级阈值（例如：信用等级不得低于 `C 级`，或对应实测得分不得低于 60 分）。
2.  **验证拦截**：当库管员尝试为特定合伙人创建“提货单（Delivery）”并点击“验证”时，系统启动自动审核。
3.  **安全判定**：
    *   **绿色状态（无感放行）**：当前实测信用评分在 60 分以上（即 A 或 B 级）。系统放行。
    *   **红色拦截（行级锁死阻断）**：若最近一次的信用评分为 D 或 E 级，系统触发强制拦截。

### 2n.3.2 信用评分严重不足强拦截与物理隔离规程 (GxP Credit Gate SOP)

1.  **提交提货单**：当库管员点击“提货验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该 CSA 合伙周期记录执行 `SELECT FOR UPDATE NOWAIT` 行级排他锁锁定，阻止并发修改信用和库存数据，阻断提货单的开具。
3.  **自动检索实时信用评分**：
    *   系统检索本会员关联的所有财务信用评分。
4.  **触发红色安全阀硬锁**：
    *   若不满足安全红线，系统强制抛出“合伙人财务账期信用评分严重低于放行红线”安全合规警告。
    *   异常将直接在操作员手持终端上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许出库或转运的物流调拨凭证。
    *   **设备物理自愈动作**：系统自动向发货口自动平移电磁道闸下发 0（保持关闭）信号，锁定当前托盘位置，并自动发送催款单自愈提醒邮件。

## 2n.4 采收分箱与物料谱系溯源 (Harvest & Matter Genealogy)

采收后的农产品打包和发货具有典型的 **分级裂变特征（1:N Fission）**（单地块收获，分裂为特级品、一级品、礼盒装等不同包装 LPN 托盘发给不同的 CSA 会员）。

### 2n.4.1 成品分选分级裂变图谱 (SOP Fruit Sorting Fission Chart)

```text
 [ 5号地块原根采收 ] ──► [ 网格多路分选线 ] ──► [ 1:N 成品包装 ] ┬──► 创始合伙礼盒-A (顺丰冷链)
                                                                └──► 常规会员散装-B (常温运输)
```

### 2n.4.2 采收分选谱系裂变追踪业务规程 (Genealogy SOP)

*   **采收打包裂变登记流程 (Sorting Fission SOP)**：
    当原果从采收卡车送抵包装线时，操作员扫描原始收获框条码，创建分选加工任务。
*   **指定母子系谱图谱继承关系**：
    系统弹出分选裂变表单，自动读取母批次收获条码，并由操作员指定分选分级生成的包装箱成品批次代号。系统在后台通过遗传双向有向无环图（DAG），自动将母批次的代码作为“父节点”注入包装箱中，继承全部历史地块、环境及药物使用记录。
*   **碳足迹分摊与一箱一码溯源证书颁发**：
    系统根据总生物量重量自动分摊前期大田施肥、水力灌溉、采收运输卡车 Scope 1 碳排、以及冷库的 Scope 2 用电排碳。成品水果在完成包装后，操作员扫描出箱单。系统自动生成每箱成品唯一的会员专属二维码标签。
*   **扫码追溯证书展现**：
    合伙人手机扫描礼盒上的二维码。系统展现该合伙农产品的可信履历：包括它的采收日期与田间网格、原辅肥料使用历史、土壤水分历史折线、光照波动历史折线、以及最核心的 GxP 放行健康状态。让消费者看得见真材实料，保证高端合伙农产品的品牌信誉。

## 2n.5 异常排查与常见自愈 (Troubleshooting)

CSA 运行期间，智能锁闭、阀门卡死及通信故障排除矩阵如下：

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-CSA-001** | 会员提货道闸在该打开时保持关闭 | 变频器过载保护跳闸或平移门电磁线圈烧毁。 | 检查电磁铁回路电阻（应处于 24 欧姆左右）；手动用测试跳线给继电器送电，清理电磁轨道铁屑。 |
| **ERR-CSA-002** | 提货页面提示 “CREDIT_SCORE_LOW” 报错 | 合伙人信用评级低于安全放行红线，系统强制锁死调拨或出库。 | 自动锁死电磁阀道闸，向会员小程序端发送催缴款短信，确认无误。 |
| **ERR-CSA-003** | 边缘网关上报 “UPLINK_TIMEOUT_ALERT” | 合伙温室地块 LoRa 控制箱断电。 | 检查太阳能板输出电压（应高于 12V 充放电控制器电压）；手动重启 LoRa 无线收发网卡自愈。 |
