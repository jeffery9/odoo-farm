## 2p.1 基础设置与生产登记 (Setup & Registration)

农产品采后精深加工业务基于分选加工流水线资产管理和科学的冷链温区时窗控制。系统通过 `farm_agricultural_processing` 模块管理加工产线、加工任务单（Mission）及分选打包配方。

### 2p.1.1 加工产线建立与任务周期建立业务规程 (Processing Setup SOP)

*   **建立分选加工线（Line）物理台账**：
    1.  登录系统，导航至“采后加工 -> 生产流水线登记”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入唯一的物理产线编码（例如：LINE-SORT-02）。
    3.  输入直观的产线名称（例如：车间一号高精度双通道重力选果流水线）。
    4.  指定生产线的“最大小时吞吐量（公斤/小时）”（例如：5000.0 kg/h）。
    5.  选择产线集成的“PLC 工业通信网关”（例如：二号 Modbus 串口网关）。
    6.  点击“保存”，系统会自动创建流水线资产档案，并初始化状态为“空闲”。

*   **初始化采后加工任务单（Mission）**：
    1.  导航至“加工任务单（Mission）”菜单并点击“新建”。
    2.  输入任务单名称（例如：2026年夏季车厘子采后机械清洗分选与冷链打包任务）。
    3.  指定加工对应的“配方/分选包装规范”（detailed_type，例如：出口级双通道车厘子分选配方）。
    4.  录入计划投料重量（例如：10000.0 kg）。
    5.  关联绑定对应的物理加工流水线。
    6.  点击“保存”，系统流水号发生器会自动在界面顶部生成唯一的加工单号（例如：PRM-2026-0034），并将状态初始化为“草稿”。

### 2p.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在加工任务单列表视图下，展示加工单号、任务名称、流水线、初始投料、当前实测包装数、出厂合格率及当前状态。利用 Odoo 19 原生行样式装饰器，数据行将根据状态自适应着色。草稿状态以淡蓝色气泡显示，“生产进行中（In Progress）”状态以绿色成功样式高亮标记，完工入库（Done）状态显示为灰色。
*   **状态机推进与工艺参数校验（State Machine Progression）**：
    表单顶部设计有动作控制按钮。状态机包括“草稿”、“进行中”、“已完工”。点击“启动生产”，系统验证关联流水线的 PLC 通信是否在线，通过后状态推进为“进行中”。
*   **字段只读控制（Read-only Constraints）**：
    为了保证工艺数据的严谨性，一旦加工任务进入“进行中”状态，加工流水线、投料计划、物料配方等核心历史字段将自动变为只读锁定状态。在“已完工”阶段，表单内所有数据字段永久只读锁定。

## 2p.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

采后冷库及流水线配料称的温度、皮带称实时净重、车间湿度等核心指标通过 Modbus TCP 协议执行高频数据遥测与冷机 PLC 变频自适应温控。

### 2p.2.1 传送带称重与冷库环境高频遥测 SOP (Scale & Cold Room IoT SOP)

*   **PLC 通信网关轮询规程**：
    安装在冷库内的数字温湿度探头和生产线配料电子称重仪表，通过 Modbus TCP 协议将参数实时推送至 Odoo 后台时序日志中。
*   **核心遥测指标解释**：
    1.  **实测冷库环境温度**：网关以寄存器数据读取实测温度值，乘以 `0.1` 缩放因子后，在 Odoo 界面渲染出高精度的摄氏度（例如：2.4°C，绿色冷库储存车厘子的黄金标准温区为 0 到 4 摄氏度）。
    2.  **实测皮带称实时流量**：网关读取实测流量寄存器，乘以 `0.1` 显示公斤数。
    3.  **变频制冷压缩机控制自愈**：当库内温度因频繁开门异常回升至 3.8°C 时，PLC 网关会自动下发高频 1 指令提升冷机变频器输出功率，自适应拉回设定温区。

### 2p.2.2 生产冷链遥测事件推送报文 (HTTP IoT Telemetry Payload)

当环境参数超出安全范围（例如库温突破 4°C 阈值）时，网关会自动向系统的 API 推送包含冷库编码、时间戳、物理检测指标：库内实际温度、相对湿度、进出库门禁状态、变频冷机运行频率、以及传感器电池电量等明文报文。

Odoo 接收到报文后，会将指标自动写入对应冷库资产的动态看板上，用作后续出库质检的安全依据。

## 2p.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

冷链物流的底线是杜绝脱冷产品出厂销售。系统设立了“冷库超温（例如高于 4°C 且持续 2 小时以上）自动出库行级排他锁定”网关。

### 2p.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：质量主管在 Odoo“参数配置”中，设定冷库冷链存储的极限最高温度上限（默认值为 `4.00°C`）。
2.  **验证拦截**：当库管员在 Odoo 尝试对果品托盘进行“出库提货（Dispatch）”或进行“冷链调拨操作”并点击“出库验证”时，系统启动自动审核。
3.  **安全判定**：
    *   **绿色状态（无感放行）**：当前实测库温不高于 `4.00°C`。系统在后台为该出库任务颁发放行凭证，允许提货。
    *   **红色拦截（行级锁死阻断）**：若最近一次的实测库温高于 `4.00°C` 且时间窗超标，系统触发强制拦截。

### 2p.3.2 库温严重超标强拦截与物理隔离规程 (GxP Cold Gate SOP)

1.  **提交成品出库单**：当库管员建立出库单并点击“出库验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该加工任务周期记录执行 `SELECT FOR UPDATE NOWAIT` 行级排他锁锁定，阻止并发修改温度和库存数据，阻断提库单的开具。
3.  **自动检索实时库温指标**：
    *   系统检索本冷库关联的所有时序库温日志。
4.  **触发红色安全阀硬锁**：
    *   若发现实测库温超标，系统强制抛出“冷库温度严重超标，货品面临脱冷变质危险”安全合规警告。
    *   异常将直接在操作员手持终端上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许出库或转入运输冷藏车车间的调拨凭证。
    *   **设备物理自愈动作**：系统自动向冷库平移门锁下发 0（强制关闭）信号，并向变频制冷压缩机下发大功率制冷信号，启动快速降温自愈。

## 2p.4 采后分选与物料谱系溯源 (Harvest & Matter Genealogy)

采后加工最典型的物料特征是 **分选规格裂变（1:N Fission）**（单批次原始收获，通过机械分选机分裂为特级品、一级品、二级品等不同规格成品包装箱及托盘 LPN）。

### 2p.4.1 成品分选分级裂变图谱 (SOP Fruit Sorting Fission Chart)

```text
 [ 2号采收批次车厘子 ] ──► [ 机械气动分选线 ] ──► [ 1:N 成品包装 ] ┬──► 特级 JJ-A (冷链包装)
                                                                └──► 普通 J-B (批发包装)
```

### 2p.4.2 分选打包谱系分裂追踪业务规程 (Processing Genealogy Traceability SOP)

*   **分选打包裂变登记流程 (Sorting Fission SOP)**：
    当原果从采收卡车送抵包装线时，操作员扫描原始收获框条码，创建分选加工任务。
*   **指定母子系谱图谱继承关系**：
    系统弹出分选裂变表单，自动读取母批次收获条码，并由操作员指定分选分级生成的包装箱成品批次代号。系统在后台通过遗传双向无环图（DAG），自动将母批次的代码作为“父节点”注入包装箱中，继承全部历史地块、环境及药物使用记录。
*   **碳足迹分摊与一托一码溯源证书颁发**：
    系统根据总生物量重量自动分摊前期大田施肥、水力灌溉、采收运输卡车 Scope 1 碳排、以及冷库的 Scope 2 用电排碳。成品水果在完成包装后，操作员扫描出箱单。系统自动生成每托成品唯一的托盘条码和二维码标签。
*   **扫码追溯证书展现**：
    消费者或零售商手机扫码，即可无缝展现从手持果盒 -> 运输车冷箱 -> 分选产线温度 -> 澄清清洗水质 -> 出库质检 -> 储藏冷库 24 小时温度折线 -> 采收卡车地磅称重单 -> 直至源头 2 号地块 PostGIS 地形边界和 GAP 化验单的完整生命周期历史。让购买者吃得放心，保证采后高品质冷链品牌信誉。

## 2p.5 异常排查与常见自愈 (Troubleshooting)

采后加工及冷链运行期间，冷机卡死、配料秤漂移及通信故障排除矩阵如下：

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-PROC-001** | 冷库库内实际温度迅速升高突破 4.0°C | 变频器过载保护跳闸、制冷压缩机冷媒泄漏、或冷库移门因结冰未完全闭合。 | 检查制冷主管道冷媒压力（应处于 1.2 到 1.5 bar 之间）；手动清理冷库移门框轨道结冰；合闸复位变频器。 |
| **ERR-PROC-002** | 出库单页面提示 “COLD_CHAIN_FAILED” 警告 | 冷库库温实测超标，系统强制锁死出库或调拨口。 | 强制锁死冷库滑升门，通知维保员紧急排查变频冷机，并手动清除冷风机表面结霜。 |
| **ERR-PROC-003** | 边缘称重仪表上报 “MODBUS_TCP_TIMEOUT” | 流水线电子配料皮带秤控制箱网线水晶头接触不良。 | 重新插拔控制箱 RJ45 防护水晶头，使用手持终端对 PLC 网络组件进行物理级重启。 |
