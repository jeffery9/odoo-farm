## 2e.1 基础设置与中药材注册 (Setup & Registration)

道地中药材（如人参、三七、黄芪）的品质受产地和环境地标（GI）地理范围约束极大。系统通过 `farm_medicinal_plants` 模块与地理空间模块管理地标台账及种质资源登记。

### 2e.1.1 中药材产地地标与种植注册业务规程 (Medicinal Registry SOP)

*   **建立道地药材产地地标档案**：
    1.  登录系统，导航至“中药材管理 -> 产地地理标志（GI）”菜单，点击“新建”。
    2.  输入直观的地标区域名称（例如：吉林白山长白山野山参地理保护区）。
    3.  输入唯一的地理标志编码（例如：GI-GINSENG-WASHAN）。
    4.  在“地理范围边界”文本域中，录入标准的 PostGIS WKT 多边形几何数据，规定道地药材种植区域边界。
    5.  点击“保存”，系统会自动验证该地标在数据库中的空间多边形格式是否合法。

*   **初始化药材种植周期**：
    1.  导航至“中药材种植周期”菜单并点击“新建”。
    2.  输入种植周期名称（例如：长白山人参六年参种植周期），并关联注册好的地理标志。
    3.  指定播种及种苗定植日期。
    4.  指定种质来源及中药材分类。
    5.  录入预计采收年龄限值（例如：6 年）。
    6.  点击“保存”，系统会自动匹配流水号发生器，在界面顶部生成全局唯一的药材周期编码（例如：MPC-2026-0005），并将当前状态初始化为“草稿”。

### 2e.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在药材种植周期列表视图下，展示药材周期编码、名称、地理地标、定植日期、品质评级及当前阶段状态。利用 Odoo 19 原生的样式装饰器，数据行将根据阶段自适应着色。草稿状态以淡蓝色气泡显示，“在田中（Growing）”状态以绿色成功样式标记。
*   **状态机推进与 GAP 安全锁（State Machine & GAP Locks）**：
    表单顶部设计有动作控制按钮。状态机包括“草稿”、“定植生长中”、“检验中”和“采收释放”。点击“定植激活”后，系统验证地块是否 100% 重合在地理保护区 WKT 围栏内，通过后状态推进为“定植生长中”。只有当药材生长期达标（如人参达到 6 年）且重金属抽检合格后，系统才允许推进至“采收释放”。
*   **字段只读控制（Read-only Constraints）**：
    为防止数据在生长期间被修改，一旦药材周期进入“定植生长中”，种质来源、地块定位和地标关联等核心物理属性变更为只读状态，Chatter 会高频记录所有定植和环境巡检。

## 2e.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

药材生长期间的环境湿度、土壤养分及昼夜变温，通过 LoRaWAN 窄带物联网网关进行高频采集与分析。

### 2e.2.1 药材大田温湿度与小气候传感器数据同步规程 (IoT Telemetry SOP)

*   **传感器高频轮询规程**：
    部署在中草药标准化种植基地（GAP 示范区）的五合一气象和小气候环境传感器，通过低功耗 LoRa 协议将现场环境指标实时上传至时序后台。
*   **核心指标解释**：
    1.  **实测气温**：网关以寄存器数据读取实测温度值，乘以 `0.1` 缩放因子后，在 Odoo 界面渲染出高精度的摄氏度（例如 22.8°C）。
    2.  **实测相对湿度**：网关读取实测相对湿度值，乘以 `0.1` 缩放因子后在系统界面显示出当前培养环境的精准百分比相对湿度。
    3.  **土壤有效水分**：网关读取土壤负压或体积含水率。若含水率低于 25% 且处于夏季高温期，系统会自动生成“温和滴灌补水”提醒，并向滴灌阀门PLC发送开启动作。

### 2e.2.2 环境遥测事件上行报文 (HTTP IoT Telemetry Payload)

当土壤有效水分或氮磷钾养分含量超出警戒红线时，网关会自动向系统的 API 网口推送状态明文报文。报文内容包括传感器名称（如：林下人参3号监测点）、时间戳、MAC地址、信号强度，以及物理检测指标：土壤温度、土壤水分体积比、氮含量、磷含量、钾含量以及光周期累积光合有效辐射度。

Odoo 接收到报文后，会将指标自动写入种植周期日记板，用于自动计算生长指数。

## 2e.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

为了通过国家中药材 GAP（中药材生产质量管理规范）认证，系统建立了严格的“重金属与农残检测 RLS（Row-Level Security）硬锁拦截门”网关。

### 2e.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：质量主管在 Odoo“参数配置”中，设定 GAP 药残及重金属（铅、镉、汞、砷）安全上限（例如：铅残留不得高于 `0.2 mg/kg`）。
2.  **录入检验单**：在采收前，第三方检测机构出具土壤与药材样本检验证书，化验员在 Odoo 建立中药材理化检验单。
3.  **安全判定**：
    *   **绿色状态（检验达标放行）**：所有重金属与残留指标均低于 GAP 安全阈值。
    *   **黄色警戒（审核提醒）**：部分环境指标微幅接近上限（如铅处于 0.15 到 0.20 之间），系统发出警告，要求技术员录入“土壤缓冲带排查”报告。
    *   **红色拦截（行级锁死阻断）**：若任何重金属（如铅）实测值高于 `0.2 mg/kg`，或者存在禁用农药检出，系统触发强制拦截网关。

### 2e.3.2 药检严重超标强制拦截与物理隔离规程 (GxP Heavy Metal Gate SOP)

1.  **提交检验验证**：当化验员提交检验结果并点击“验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该种植周期执行 `FOR UPDATE` 行级锁定，防止并发修改验证数据，阻断采收单的开具。
3.  **自动检索实时重金属指标**：
    *   系统检索本周期关联的所有理化指标。
4.  **触发红色安全阀硬锁**：
    *   若不满足安全红线，系统强制抛出“中药材重金属或禁用农药严重超标”安全警告。
    *   异常将直接在操作员手持终端上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许出炉或转入鲜切车间的出库调拨单。
    *   **联动物理设备隔离动作**：系统自动将对应地块的状态变更为“重污染检疫隔离”，向地磅放行道闸下发锁定信号保持关闭，并自动拉起自愈警报，启动物理土地客土净化和排水阻断自愈流程。

## 2e.4 趁鲜加工与物料谱系溯源 (Harvest & Matter Genealogy)

道地药材高度强调 **趁鲜加工（Fresh Processing）**。原根采收后必须在几小时内进行清洗、分级、干燥与切片，形成完全的 **1:N 鲜切片谱系分裂（Fission）**。

### 2e.4.1 趁鲜鲜切加工与分级图谱 (SOP Fresh Processing Chart)

```text
 [ 药材原根采收批次 ] ──► [ 清洗与分级 ] ──► [ 1:N 鲜切片 ] ┬──► 优质切片-A (包装出厂)
                                                          └──► 普通切片-B (烘干备用)
```

### 2e.4.2 趁鲜加工谱系分裂追踪业务规程 (Processing Genealogy Traceability SOP)

*   **趁鲜加工切片登记流程**：
    当原参从地块挖出并送抵加工车间切片机时，操作员扫描原根周转箱条码，创建趁鲜加工加工任务。
*   **指定母子血缘继承关系**：
    系统弹出趁鲜加工裂变表单，自动读取母批次原根条码，并由操作员指定接种生成的切片成品批次代号。系统在后台通过遗传双向无环图（DAG），自动将母批次的代码作为“父节点”注入切片成品中。
*   **药效品质指标传导逻辑**：
    如果在母批次（地块）中曾经记录过重金属超标或农药超标，该标记会自动通过谱系算法，向下传导到所有分裂生成的切片成品上，使其自动继承“不合规检疫评级”并阻止出库销售。
*   **出厂包装与二维码溯源证书展现**：
    切片在完成包装后，操作员扫描出箱单。系统自动生成该中药材个体的唯一身份证二维码标签（张贴在药材包装盒上）。购买者通过手机扫描标签，可直接展现无缝的双向谱系追溯证书：直观展现从药房药盒 -> 鲜切切片批次 -> 烘干温度曲线 -> 趁鲜清洗时间 -> 采收卡车地磅称重单 -> 种植周期 GAP 检测 -> 直至最初长白山地理标志 PostGIS 多边形地块边界的完整历史生长环境、重金属检测与无菌操作日志，确保道地药材品质信誉。

## 2e.5 异常排查与常见自愈 (Troubleshooting)

中草药种植期间，地标拓扑失效、重金属超标拦截及传感器失联排除矩阵如下：

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-MED-001** | 手持终端新建地块提示 “GI_OUT_OF_BOUNDS” 报错 | 种植地块边界与地理标志（GI）的多边形拓扑未完全重合。 | 打开 GIS 地图工具，使用边界融合指令重新校准地块边界的多边形，确保其落在 GI 围栏内。 |
| **ERR-MED-002** | 药检页面提示 “HEAVY_METAL_BLOCKED” 报错 | 铅、镉、汞、砷等重金属化验超标，事务回滚。 | 锁定地块物料出库，物理隔离当前批次，向地磅放行道闸下发 0（保持关闭）信号，并自动启动客土治理自愈。 |
| **ERR-MED-003** | 边缘网关上报 “LORA_SIGNAL_WEAK” 警告 | 大田林下障碍物遮挡导致 LoRa 射频信号严重衰减。 | 将林下传感器天线升级为高增益玻璃钢天线，并增加信号中继节点提升 RSSI 与 SNR。 |

### 📐 物理数学计算模型：活性成分干燥收缩率与 PHI 化学衰减

Agri-OS 在药用植物（如人参、甘草）采收期使用以下物理衰减指数模型：

1. **药材干燥折干率 (Shrinkage Ratio)**:
   [ Shrinkage_Ratio ] = [ Dry_mass ] / [ Fresh_mass ] * 100

2. **农残及重金属化学半衰期衰减模型 (Chemical Decay)**:
   [ Residue_t ] = [ Initial_concentration ] * EXP( - [ k_decay ] * [ Days_elapsed ] )
   ASSERT [ Residue_t ] <= [ MRL_maximum_residue_limit ]
   *   `k_decay`: 农药专属半衰期常数。系统以此自适应预测并提前提示种植户安全的采收合规窗口。
