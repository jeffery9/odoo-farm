## 2k.1 基础设置与网箱登记 (Setup & Registration)

特色海洋养殖基于 PostGIS 滩涂确权网格边界与海洋苗种批次控制。系统通过 `farm_aquaculture` 模块管理浅海网箱、滩涂确权多边形及特色海洋苗种。

### 2k.1.1 滩涂网格建档与投放建立业务规程 (Specialty Setup SOP)

*   **建立特色浅海网箱与滩涂确权台账**：
    1.  登录系统，导航至“特色养殖 -> 浅海确权台账”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入唯一的物理区划编码（例如：ZONE-MARINE-C02）。
    3.  输入直观的网格名称（例如：大连广鹿岛东海域底播海参 2 号确权区）。
    4.  在“空间多边形 WKT”文本域中，录入标准的 PostGIS 多边形二维几何坐标串，界定该海参底播滩涂的合法确权边界。
    5.  指定确权滩涂的“水底材质物理属性（Substrate）”，支持：
        *   `礁石沙地 (reef_sandy)`：海参附着生长的黄金底质。
        *   `淤泥质滩涂 (silty_mud)`：适合贝类及部分蟹类底播。
        *   `沙砾海床 (gravel_bed)`：适合鲍鱼增殖放流。
    6.  点击“保存”，系统会自动验证空间多边形格式合法性，状态初始化为“有效”。

*   **初始化底播繁育周期批次**：
    1.  导航至“海珍品繁育批次”菜单并点击“新建”。
    2.  输入繁育批次名称（例如：2026年广鹿岛春季底播海参参苗周期）。
    3.  指定投放的“物料/海珍品苗种”（detailed_type，例如：辽刺参一龄幼参苗）。
    4.  输入投放的“初始单重规格（头/公斤）”（例如：200 头/kg）。
    5.  选择上述登记的物理滩涂确权网格。
    6.  点击“保存”，系统流水号发生器会在表单上方生成唯一的海洋周朝号（例如：MRB-2026-0045），并将当前状态初始化为“草稿”。

### 2k.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在海珍品繁育批次列表视图下，展示海洋周朝号、批次名称、滩涂网格、水底材质、初始单重、当前估算存栏生物量、最新水下温度及当前状态。行数据根据状态动态变色：草稿状态以蓝色信息气泡显示，“底播繁育中（Growing）”状态以绿色成功样式标记。
*   **状态机推进与空间范围校验（State Machine Progression）**：
    表单顶部设计有动作控制按钮和进度状态。点击“底播激活”时，系统启动边界空间校验，如果底播地块 100% 重合在浅海确权 WKT 多边形围栏内，状态推进为“底播繁育中”；采收完工时，点击“捕捞结算”，状态流转为“已完工”。
*   **字段只读控制（Read-only Constraints）**：
    为了保证生物资源数据的物理防篡改，一旦批次进入“底播繁育中”状态，海珍品苗种、滩涂确权网格、初始头数等核心历史字段将自动变为只读锁定状态。在“已完工”阶段，表单内所有字段将永久只读锁定。

## 2k.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

浅海滩涂部署有水下摄像头、浮标式多通道盐度计、波浪传感器，通过 4G/LoRa 网关实现高频数据轮询，并执行水下计算机视觉（CV）估计。

### 2k.2.1 水下 ROV 视觉生物量估计与浮标遥测规程 (ROV CV Telemetry SOP)

*   **水下多目相机生物量估计规程**：
    ROV 搭载的水下多目立体相机会定时扫描礁石海底。系统利用水下双目深度估计与计算机视觉目标识别技术，自动识别出海参个体的轮廓尺寸。
*   **核心遥测指标解释**：
    1.  **实测估算单重**：AI 视觉模型自动评估出海参个体的平均体长和估算单重（克，例如：120 克/头）。
    2.  **实测底栖密度**：AI 在 3D 立体视觉投影空间内，计算每平方米礁石上的海参数量。
    3.  **海水盐度与温度监测**：浮标高频传感器测量海水的实际盐度（乘以 `0.1` 缩放因子后在 Odoo 界面显示，例如：31.4‰）与温度（例如 14.2°C），用于分析底播海参进入夏眠周期的生理窗口。

### 2k.2.2 浮标高频遥测推送报文 (HTTP IoT Telemetry Payload)

当传感器探测到台风海啸、风暴潮引起的剧烈盐度倒灌或潮位异常波动时，浮标网关会自动向 Odoo 物理 API 接口推送滩涂编码、时间戳、物理检测指标：盐度、水温、实测潮位高度（米）、波浪有效波高、实测底栖密度以及电池电压等明文报文。

Odoo 接收到报文后，会将指标关联至该滩涂确权区承载的所有海洋繁育周期上，作为灾害风险评估的数据源。

## 2k.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

海珍品养殖中，夏季台风、风暴潮或赤潮引起的突发低氧、超温（例如水温高于 28°C 会导致海参化皮死亡）会导致全场绝收。系统设立了“潮位与温度异常安全放行阀硬锁”网关。

### 2k.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：水产主管在 Odoo“参数配置”中，设定所养海珍品允许的极限最高温度上限（默认值为 `28.00°C`）与最低溶解氧红线。
2.  **验证拦截**：当技术员尝试为特定滩涂派发“采收任务（Mission）”或进行“潜水捕捞操作”并点击“验证”时，系统启动自动审核。
3.  **安全判定**：
    *   **绿色状态（无感放行）**：当前实测水温不高于 `28°C`。系统在后台为该事务颁发放行凭证，允许采收。
    *   **红色拦截（行级锁死阻断）**：若最近一次的实测水温高于 `28°C`，系统触发强制拦截。

### 2k.3.2 异常超温严重违规强拦截与物理隔离规程 (GxP Shore Gate SOP)

1.  **提交采收调拨单**：当技术员建立捕捞并点击“验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该海洋繁育周期记录执行 `SELECT FOR UPDATE NOWAIT` 行级排他锁锁定，阻止并发修改水温或健康状态数据，阻断采收捕捞单的开具。
3.  **自动检索实时海洋环境**：
    *   系统检索本滩涂确权区关联的所有浮标时序温度日志。
4.  **触发红色安全阀硬锁**：
    *   若不满足安全红线，系统强制抛出“滩涂水温严重高于安全阈值，海参面临化皮强应激”安全合规警告。
    *   异常将直接在操作员手持终端上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许出海捕捞或转入深加工车间的调拨凭证。
    *   **设备物理自愈动作**：系统自动向浅海遮阳网阀门 PLC 下发 1（强制展开）指令降低浅表光照，向多孔曝气管道阀门下发 1 指令，启动海底强制冷水层曝气，并拉起故障自愈和报警流程。

## 2k.4 海珍捕捞与物料谱系溯源 (Harvest & Matter Genealogy)

海参捕捞具有典型的 **分级裂变特征（1:N Fission）**（单滩涂潜水捕捞，通过重力分级机分裂为特大级、大级、中级海参成品包装 LPN）。

### 2k.4.1 海珍品捕捞分选裂变图谱 (SOP Sea Cucumber Harvesting Chart)

```text
 [ 2号滩涂底播海参捕捞 ] ──► [ 自动重力分级机 ] ──► [ 1:N 成品包装 ] ┬──► 特大刺参-A (冷链包装)
                                                                 └──► 普通刺参-B (盐渍包装)
```

### 2k.4.2 捕捞分选裂变谱系追踪业务规程 (Harvesting Genealogy SOP)

*   **捕捞分选登记流程**：
    当潜水员将海参捕捞上船并送抵海珍品加工车间分选线时，操作员扫描周转箱条码，创建捕捞分选任务。
*   **指定母子系谱图谱继承关系**：
    系统弹出捕捞裂变表单，自动读取母批次滩涂条码，并由操作员指定分级生成的成品批次代号。系统在后台通过遗传双向无环图（DAG），自动将母批次的海域周期作为“父节点”注入包装箱中。
*   **分摊碳足迹与一箱一码溯源证书颁发**：
    系统根据总生物量重量自动分摊前期浮标、ROV水下视觉巡检用电、加工清洗的 Scope 1 总排碳。海参在完成包装后，操作员扫描出箱单。系统自动生成每箱成品唯一的二维码标签。
*   **扫码追溯证书展现**：
    消费者通过手机扫描包装箱或海参精装礼盒上的二维码。系统展现该成品海参的可信履历：包括它的潜水捕捞日期与养殖滩涂、底播种苗来源、底质物理属性、养殖期间的历史水温与盐度波动折线、以及最核心的 GxP 放行健康状态。让消费者看得见真材实料，保证高端辽刺参的品牌信誉。

## 2k.5 异常排查与常见自愈 (Troubleshooting)

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-MAR-001** | 水下多目相机无法上报生物量估算 | 镜头表面被藤壶、微藻等海洋生物严重附着遮挡。 | 调派 ROV 启动物理刮刷机构清理镜头表面，或使用防污涂料自愈刷涂天线。 |
| **ERR-MAR-002** | 捕捞页面提示 “TEMP_CRITICAL_BLOCKED” 警告 | 海域实测温度高于 28°C 红线，当前底播批次已被强制锁死。 | 海底多孔曝气阀自动开到最大，引入海洋深层冷水，确认供电变频继电器完好。 |
| **ERR-MAR-003** | 边缘浮标网关上报 “SALINITY_DROPPED” 告警 | 暴雨导致近岸滩涂淡水倒灌，盐度跌至 24‰ 危险值以下。 | 系统自动向浅海溢流风向PLC发送关闭信号，限制地表淡水流入。 |
