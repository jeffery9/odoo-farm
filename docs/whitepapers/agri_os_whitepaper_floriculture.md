## 2c.1 基础设置与组培注册 (Setup & Registration)

组培花卉生长极度依赖无菌世代管理和精确的培养环境定位。系统通过 `farm_floriculture` 和 `farm_protected_cultivation` 模块管理组培批次及设施资产绑定。

### 2c.1.1 组培批次建立业务规程 (Floriculture Batch Setup SOP)

*   **建立组培繁育批次**：
    1.  登录系统，导航至“设施花卉 -> 组培批次”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入直观的批次名称（例如：黄金小蝴蝶兰 G1 世代繁育批次）。
    3.  选择对应的“原物料/原种母本”，系统会自动在后台限制只允许选择合规的花卉原种（detailed_type 为消耗品/无菌亲本）。
    4.  选择当前繁育的物理“繁育阶段（Generation Stage）”，支持：
        *   `G0 启动代 (g0_init)`：外植体无菌初始化阶段。
        *   `G1 增殖代 (g1_multi)`：丛生芽切割高频增殖阶段。
        *   `G2 生根代 (g2_root)`：诱导生根，形成完整植株。
        *   `G3 炼苗代 (g3_acclim)`：出瓶驯化适应大自然。
    5.  关联该批次对应的物理“培养设备/智能培养箱”，确保每个生物资产拥有明确的三维地理与设备空间定位。
    6.  录入本次接种的初始“接种总瓶数”（例如：500 瓶）。
    7.  点击“保存”，系统会自动检索后台的流水号发生器，在界面顶部生成全局唯一的组培批次号（例如：FPB-2026-0008）。

### 2c.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在花卉组培批次列表视图下，展示组培批次号、批次名称、母本、繁育阶段、关联培养箱、接种总瓶数和状态。通过后台原生的布尔值样式装饰器，数据行将根据阶段自适应着色。启动代（G0）以蓝色信息气泡显示，培养中（Cultivating）状态以绿色成功样式标记。
*   **状态机推进（State Machine Progression）**：
    表单顶部设计有动作控制按钮和面包屑进度。批次刚建立时状态为“草稿”。点击“启动培养”按钮，系统将验证母本和设备绑定是否齐全，通过后状态推进为“培养中”，并对培养箱的传感器配置下发监测指令。点击“完工释放”按钮，系统会自动核算该批次的合格瓶数，并将状态推向“完工释放”。
*   **字段只读控制（Read-only Constraints）**：
    为防止数据在培养中途被非授权修改，一旦批次推进到“培养中”状态，原种母本、接种总瓶数及繁育代次将自动变为只读锁定状态。在“完工释放”阶段，表单内所有字段将永久只读锁定。

## 2c.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

组培室物理微气候参数通过 Modbus RTU 工业 PLC 控制器进行高频数据采集和环境自适应调控。

### 2c.2.1 组培室温湿度与补光网关通信 SOP (Modbus IoT Integration)

*   **PLC 通信网关轮询规程**：
    安装在组培架上的五合一工业环境传感器，通过 Modbus 协议将微气候物理数据高频推送至 Odoo 后台时序表。
*   **核心遥测指标解释**：
    1.  **实测温度**：网关以寄存器数据读取温度值，乘以 `0.1` 缩放因子后，在 Odoo 界面渲染出高精度的摄氏度（例如 24.5°C）。
    2.  **实测相对湿度**：网关通过相对湿度寄存器值，乘以 `0.1` 在系统界面显示出当前培养环境的精准百分比相对湿度（例如 65.2%）。
    3.  **制冷阀状态**：监控湿帘水泵或空调电磁阀继电器的开合状态，系统根据实测温度自动下发开（1）或关（0）的数字信号。
    4.  **补光 LED 状态**：根据预设的定时光周期任务，网关向补光继电器写入 1（开启补光）或 0（关闭补光）。

### 2c.2.2 组培室内遥测事件上行推送 (HTTP IoT Telemetry Payload)

当环境参数超出预警限时，边缘端采集网关会自动向系统的 API 网口推送状态明文报文。报文内容包括传感器名称（如：组培B室3号架）、时间戳、MAC地址、信号强度，以及最核心的物理检测指标：温度、湿度、二氧化碳浓度、当前光照度（例如 1500.0 Lux）以及组培架各层 LED 补光灯的工作电流（安培）。

Odoo 接收到报文后，会将温湿度关联至该组培箱承载的所有组培批次上，用以累积光照度时数。

## 2c.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

在花卉组培生产中，接种污染率（如霉菌、细菌污染）是高风险指标。系统设立了“污染率红线自动拦截与自愈强制消毒”网关。

### 2c.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：生产主管在 Odoo“参数配置”中，设定接种允许的最大污染率上限（默认值为 `10%`）。
2.  **日常报损**：技术员在培养检查时，通过手持终端记录每日的污染废弃瓶数。
3.  **安全判定**：
    *   **绿色状态（无感放行）**：累计污染率低于 `5%`，允许进行常规的切割转接和正常出瓶。
    *   **黄色警戒（人工说明）**：累计污染率处于 `5%` 到 `10%` 之间，系统弹窗发出警告。技术员必须在确认日志中录入“局部污染原因排查”说明，方可继续激活。
    *   **红色拦截（事务锁死）**：当某一繁育批次的累计污染率突破 `10%` 时，系统触发强制拦截网关。

### 2c.3.2 污染率强制拦截与自愈控制规程 (GxP Cleanliness Gate SOP)

1.  **提交检验单**：当质检员建立“组培污染报损单”并点击“验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该组培批次执行行级锁定，防止并发修改污染瓶数。
3.  **自动计算累计污染率**：
    *   系统检索该批次历史所有的污染报损记录，并折算：`污染率 = 累计报损瓶数 / 初始接种总瓶数`。
4.  **触发红色安全阀硬锁**：
    *   若计算结果超过 10%，系统强制抛出“组培室洁净度严重超标”安全警告。
    *   异常将直接在操作员手持终端上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许后续切割转接的出库单。
    *   **联动设备自愈动作**：系统自动将该批次的状态变更为“检疫隔离”，并在关联智能培养箱的 PLC 继电器下发指令，强制锁定电磁阀防止物料被移出；同时，自动向组培室杀菌阀发送指令，强制激活 UV-C 杀菌灯进行 30 分钟无缝物理空气消毒。

## 2c.4 繁育分裂与物料谱系溯源 (Harvest & Matter Genealogy)

花卉组培具有典型且高频的 **1:N 世代裂变（Fission）**特征（单瓶丛生芽切成多瓶）和 **N:1 拼箱（Blending）**特征。

### 2c.4.1 世代裂变与无菌合并图谱 (SOP Fission Blending Chart)

```text
                               ┌──► 子批次-G1-01 (150瓶苗)
                               │
 [ 母批次-G0 ] ──► [ 1:N 裂变 ] ├──► 子批次-G1-02 (200瓶苗)
                               │
                               └──► 子批次-G1-03 (180瓶苗)
```

### 2c.4.2 组培谱系分裂追踪业务规程 (Fission Genealogy Traceability SOP)

*   **裂变接种登记流程**：
    当一瓶 G0 丛生芽被技术员放入超净工作台切割转接成 10 瓶新的 G1 生根苗时，操作员在手持终端点击“接种分裂”。
*   **指定母子血缘继承关系**：
    系统弹出批次裂变表单，自动读取母批次条码，并由操作员指定接种生成的子批次代号。系统在后台通过遗传双向无环图（DAG），自动将母批次的代码作为“父节点”注入子批次中，实现完全的血缘追溯继承。
*   **母本缺陷基因与品质传导逻辑**：
    如果在母批次（G0）中曾经记录过基因突变（如：叶绿素条斑化病变），该标记会自动通过谱系算法，向下无限传导到所有分裂生成的子批次上，使其自动继承“低品质评级”。
*   **出瓶移栽与二维码溯源证书颁发**：
    子批次在完成 G2 诱导生根，并经过 G3 炼苗出瓶移栽到温室苗盘后，操作员扫描出瓶单。系统自动生成该花卉个体的唯一身份证二维码标签（张贴在营养钵上）。购买者通过手机扫描标签，可直接展现无缝的双向谱系追溯证书：直观展现从温室苗盘 -> G3 炼苗箱 -> G2 生根架 -> G1 增殖超净工作台 -> 直至最初 G0 组培室无菌母本培养箱的完整历史生长环境、施药记录与无菌操作日志，确保高档花卉品质信誉。

## 2c.5 异常排查与常见自愈 (Troubleshooting)

组培运行期间，温室光照漂移、高污染及继电器失联排除矩阵如下：

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-TC-001** | 培养架 LED 补光灯在该亮起时保持熄灭 | 定时控制器 Modbus 继电器线圈被物理锁定或总线失联。 | 现场检查 RS-485 信号线终端电阻（应为 120 欧姆）；手动测试 PLC 继电器控制线圈电压。 |
| **ERR-TC-002** | 组培接种批次页面提示 “CLEANLINESS_CRITICAL” 警告 | 接种污染率超过 10% 警戒上限，批次被全线锁定。 | 停止该地块一切出库与切割，对操作员手持终端进行消毒登记，对无菌培养箱强制执行 UV-C 杀菌自愈动作。 |
| **ERR-TC-003** | 边缘采集网关报错 “UPLINK_BUFFER_FULL” | 本地网络波动，网关与 Odoo 物联网 HTTP 接口失联超过 1 小时。 | 检查组培室 Wi-Fi 或蜂窝网关。网关会自动检索本地 SQLite 缓存，并在网络自愈后自动重传数据。 |

### 📐 物理数学计算模型：日累积光照 (DLI) 与饱和汽压差 (VPD)

Agri-OS 在花卉温室中使用以下物理公式控制环境调节阀：

1. **日累积光照积分 (Daily Light Integral - DLI)**:
   [ DLI ] = [ PPFD_average (umol/m2/s) ] * [ Photoperiod (hours) ] * 0.0036
   *   `PPFD`: 光合有效辐射光子通量密度。DLI 必须严格控制在目标花卉（如玫瑰 10-12 mol/m2/day）区间内，自动控制遮阳网。

2. **空气饱和汽压差 (Vapor Pressure Deficit - VPD)**:
   [ VPD (kPa) ] = [ VPS_saturation ] * ( 1 - [ RH_relative_humidity % ] )
   [ VPS_saturation ] = 0.61078 * EXP( ( 17.27 * [ Temperature_C ] ) / ( [ Temperature_C ] + 237.3 ) )
