## 2j.1 基础设置与水池登记 (Setup & Registration)

工厂化循环水养殖高度依赖于高密度的水动力物理设施管理和严格的幼体引入期控制。系统通过 `farm_aquaculture` 模块管理水池资产、鱼苗投放批次及转池分级配方。

### 2j.1.1 循环水池与投放批次建立业务规程 (RAS Setup SOP)

*   **建立循环水池（Tank）物理台账**：
    1.  登录系统，导航至“循环水养殖 -> 水池资产登记”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入唯一的物理水池编码（例如：TANK-RAS-A03）。
    3.  输入直观的水池名称（例如：循环水车间 A 栋 3 号高密度养殖池）。
    4.  指定水池设计的“最大装载容量（立方米）”（例如：120.0 立方米）。
    5.  关联水池所属的物理“排污过滤回路系统”（例如：一号 RAS 回路）。
    6.  点击“保存”，系统会自动创建水池资产档案，并初始化状态为“空闲”。

*   **初始化鱼苗投放周期批次**：
    1.  导航至“鱼苗投放批次”菜单并点击“新建”。
    2.  输入批次名称（例如：2026年夏季大西洋鲑鱼苗投放批次）。
    3.  指定投放的“物料/鱼苗品种”（detailed_type，例如：三倍体大西洋鲑鱼苗）。
    4.  输入投放的“初始规格（克/尾）”（例如：15.0 克）。
    5.  输入投放的“初始尾数”（例如：10000 尾）。
    6.  选择并绑定对应的物理水池。
    7.  点击“保存”，系统会自动调用流水号生成器，在表单上方生成唯一的投放周期号（例如：AQB-2026-0012），并将当前状态初始化为“草稿”。

### 2j.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在鱼苗投放批次列表视图下，展示投放周期号、批次名称、水池、初始尾数、当前估算生物量（kg）、水体溶氧量及当前状态。利用原生样式装饰器，数据行将根据状态自适应着色。草稿状态以淡蓝色气泡显示，“在池繁育中（Growing）”状态以绿色成功样式高亮标记，转池分箱或已捕捞（Harvested）状态显示为灰色。
*   **状态机推进与安全限校验（State Machine & Checks）**：
    表单顶部设计有动作控制按钮。状态机包括“草稿”、“繁育中”、“分级转池中”和“已捕捞”。点击“启动繁育”时，系统验证当前水池水质传感器状态，若温度、溶氧及 pH 参数全部在线且正常，状态推进为“繁育中”。
*   **字段只读控制（Read-only Constraints）**：
    为了保证养殖系谱的原始真实性，一旦状态推进到“繁育中”状态，鱼苗品种、初始尾数、水池等核心字段将自动变更为只读锁定状态。在“已捕捞”阶段，表单内所有字段将永久只读锁定。

## 2j.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

工厂化循环水（RAS）的核心是水循环和精密水质维持。系统通过 Modbus TCP 协议高频轮询溶氧仪、温控仪、砂缸压差阀，实现高频上行与联动自愈。

### 2j.2.1 循环水高频水质 PLC 遥测 SOP (RAS IoT SOP)

*   **PLC 通信网关轮询规程**：
    安装在水池中的多合一水质探头和砂缸差压变送器，通过 Modbus RTU 转 TCP 协议将数据上报至系统时序底盘。
*   **核心遥测指标解释**：
    1.  **实测溶解氧（DO）**：网关以寄存器数据读取实测溶解氧值，乘以 `0.1` 缩放因子后，在 Odoo 界面渲染出高精度的毫克/升（例如：7.8 mg/L）。
    2.  **实测水体 pH 值**：网关读取 pH 寄存器值，乘以 `0.01` 缩放因子后显示（例如：7.35 pH）。
    3.  **砂缸过滤器进出口压差值**：监测砂缸堵塞状态的核心指标，若压差高于 0.8 bar，系统会自动向 PLC 下发砂缸反冲洗电磁阀开关指令。

### 2j.2.2 水质遥测数据包格式 (HTTP IoT Telemetry Payload)

当环境参数超出安全范围时，边缘采集网关会自动向系统的 API 推送包含水池编码、时间戳、物理检测指标：水温、溶解氧浓度、水体 pH 值、电导率、以及防逃逸格栅阀门开度等明文报文。

Odoo 接收到报文后，会将指标关联至该水池承载的所有繁育周期上，用以累积环境压力指数。

## 2j.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

高密度养殖中，溶解氧低于阈值（例如低于 4.5 mg/L）会导致大规模窒息死亡。系统设立了“溶解氧低于安全红线自动行级排他锁定”网关。

### 2j.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：水产主管在 Odoo“参数配置”中，设定所养鱼类的溶解氧极限红线（默认值为 `4.50 mg/L`）。
2.  **验证拦截**：当现场技术员尝试对鱼池进行“常规饲料投喂（Feed）”或进行“转池调拨操作”并点击“验证”时，系统启动自动审核。
3.  **安全判定**：
    *   **绿色状态（无感放行）**：当前实测溶解氧不低于 `4.5 mg/L`。系统在后台为该事务颁发放行凭证，允许操作。
    *   **红色拦截（行级锁死阻断）**：若最近一次的实测溶解氧低于 `4.5 mg/L`，系统触发强制拦截。

### 2j.3.2 溶解氧严重超标强拦截与物理隔离规程 (GxP DO Gate SOP)

1.  **提交饲喂或调拨单**：当技术员建立调拨并点击“验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该繁育周期记录执行 `SELECT FOR UPDATE NOWAIT` 行级排他锁锁定，阻止并发修改水质数据，阻断调拨单的开具。
3.  **自动检索实时溶解氧**：
    *   系统检索本水池关联的所有时序溶氧日志。
4.  **触发红色安全阀硬锁**：
    *   若不满足安全红线，系统强制抛出“溶解氧严重低于安全阈值”安全合规警告。
    *   异常将直接在操作员手持终端上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许调拨或出池清仓调拨凭证。
    *   **设备物理自愈动作**：系统自动向增氧机变频 PLC 写入 1（功率提升至 100%），开启纯氧强制溶入管道阀门，向备用供水泵PLC下发启动指令引入纯净富氧水，并拉起故障自愈和报警流程。

## 2j.4 捕捞收获与物料谱系溯源 (Harvest & Matter Genealogy)

大西洋鲑等成鱼捕捞具有典型的 **分级裂变特征（1:N Fission）**（单池捕捞，通过自动分选机分裂为不同单重规格、肉色评级的精装箱及托盘 LPN）。

### 2j.4.1 成鱼捕捞分级裂变图谱 (SOP Salmon Harvesting Chart)

```text
 [ 3号水池成鱼捕捞 ] ──► [ 自动重力色选机 ] ──► [ 1:N 成品包装 ] ┬──► 特级鲑鱼肉-A (冷链包装)
                                                               └──► 一级鲑鱼肉-B (烘干包装)
```

### 2j.4.2 捕捞分选裂变谱系追踪业务规程 (Harvesting Genealogy SOP)

*   **捕捞分选登记流程**：
    当成鱼从水池中捕捞出来并送入加工车间分选线时，操作员扫描周转箱条码，创建捕捞分选任务。
*   **指定母子系谱图谱继承关系**：
    系统弹出捕捞裂变表单，自动读取母批次水池条码，并由操作员指定分级生成的成品批次代号。系统在后台通过遗传双向无环图（DAG），自动将母批次的水池周期作为“父节点”注入包装箱中，继承全部历史环境、药物使用记录。
*   **分摊碳足迹与一箱一码溯源证书颁发**：
    系统根据总生物量重量自动分摊前期水池循环水泵电力消耗、过滤反冲洗、饲料投入的 Scope 1 总排碳。种子在完成包装后，操作员扫描出库单。系统自动生成每箱成品唯一的二维码标签。
*   **扫码追溯证书展现**：
    海鲜消费者通过手机扫描鱼肉包装上的二维码。系统展现该成品鲑鱼的可信履历：包括它的捕捞日期与养殖水池、养殖期间的历史水温与溶解氧波动折线、饲喂配方、以及最核心的 GxP 放行健康状态。让消费者吃得放心，保证工厂化高端鲑鱼的食品安全信誉。

## 2j.5 异常排查与常见自愈 (Troubleshooting)

循环水运行期间，增氧故障、溶氧异常及传感器通信故障排除矩阵如下：

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-AQU-001** | 水池内溶解氧严重低于 4.5 极限 | 射流增氧泵皮带物理断裂或纯氧过滤器电磁阀机械卡死。 | 更换增氧泵电机皮带；检查气动纯氧阀进气压力（应在 0.3 到 0.5 bar 之间）；手动测试电磁阀线圈。 |
| **ERR-AQU-002** | 调拨页面提示 “DO_CRITICAL_BLOCKED” 警告 | 水体实测溶解氧低于 4.5 红线，当前周期已被强制锁死。 | 增氧泵功率自动提至 100%，引入备用纯氧管道，确认供电变频继电器完好。 |
| **ERR-AQU-003** | 砂缸过滤进出口压差高于 0.8 bar 告警 | 滤砂长期未反洗，微滤有机杂质严重淤积。 | 系统自动控制气动执行器执行反冲洗，检查排污气动球阀反馈信号。 |

### 📐 物理数学计算模型：循环水溶解氧 (DO) 平衡与日投喂量自动计算

Agri-OS 在 RAS (循环水水产养殖) 模块中对高密度鱼池环境应用以下时序计算模型：

1. **溶解氧饱和平衡度 (DO Saturation Degree)**:
   [ DO_Saturation_mg/L ] = ( 14.621 - 0.4477 * [ Temp_C ] + 0.0083 * [ Temp_C ]^2 ) * [ Pressure_correction_factor ]
   ASSERT [ Actual_DO_mg/L ] >= 5.0 mg/L (一旦低于 5.0 触发 120 PSI 纯氧泵变频充氧)

2. **高频鱼池日投喂量 (Daily Feed Ration)**:
   [ Daily_Feed_Mass (kg) ] = [ Total_estimated_fish_biomass (kg) ] * [ Feeding_rate_coefficient % ] * [ Temperature_scaling_factor ]
