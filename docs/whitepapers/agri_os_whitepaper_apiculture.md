## 2i.1 基础设置与蜂群登记 (Setup & Registration)

精准养蜂业务基于蜂箱物理资产 RFID 芯片建档及蜂王世代谱系树控制。系统通过 `farm_apiculture` 模块管理蜂箱资产、蜂群批次与繁育系谱。

### 2i.1.1 蜂箱蜂群建档与系谱登记业务规程 (Apiculture Registration SOP)

*   **建立蜂箱与蜂群物理台账**：
    1.  登录系统，导航至“精准养蜂 -> 蜂箱资产登记”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入或扫描蜂箱上安装的 RFID 唯一物理标识（例如：RFID-BEE-HIVE-082）。
    3.  输入直观的蜂箱名称（例如：长白山椴树蜜移动蜂箱 03 号）。
    4.  选择当前蜂群的“蜂王品种”（detailed_type，例如：意大利蜂纯系）。
    5.  指定该蜂箱当前摆放的“蜜源位置/林区”（例如：长白山红松阔叶混交林 A 区）。
    6.  点击“保存”，系统会自动创建蜂箱资产档案，状态初始化为“在箱中”。

*   **建立蜂王繁育系谱档案**：
    1.  导航至“蜂王遗传系谱”菜单并点击“新建”。
    2.  输入蜂王编码，并关联上述登记的蜂箱批次。
    3.  选择对应的“母本蜂王（Queen Mother）”。
    4.  录入预计产卵活性，点击“保存”，系统在后台自动构建蜂王世系谱系树，支持多代回溯审计。

### 2i.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在蜂群批次列表视图下，展示蜂箱 RFID、蜂王品种、存栏框数、昨日重量、最新检疫状态及当前状态。利用 Odoo 19 原生列表行装饰器，数据行将根据检疫状态自适应着色。健康（Healthy）状态以绿色成功样式显示，隔离检疫中（Quarantine）则以黄色警戒样式高亮显示。
*   **表单视图控制与状态机推进（Form View & State Machine）**：
    表单顶部设计有动作控制按钮和面包屑进度。蜂群批次状态机包括“草稿”、“繁育生长中”、“采蜜转场中”、“已清棚归档”。通过状态机引擎（State Machine Engine）将牲畜生命周期迁移至活动健康状态，状态推进为“繁育生长中”；进入转场放牧蜜源地时，点击“转场激活”，状态变更为“采蜜转场中”。
*   **字段只读控制（Read-only Constraints）**：
    为了保证科研系谱数据的严谨，一旦蜂群批次推进到“采蜜转场中”状态，蜂王品种、初始巢脾框数及母本蜂王将自动变为只读锁定状态。在“已清棚归档”阶段，表单内所有数据字段永久只读锁定。

## 2i.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

林下蜂箱部署有太阳能移动物联网网关，高频上行蜂箱重量、箱内温度及湿度指标，用于远程研判花蜜积聚速度与分蜂预警。

### 2i.2.1 移动蜂箱重量与温湿度遥测规程 (IoT Weight Scale SOP)

*   **称重传感器高频轮询规程**：
    安装在蜂箱底部的太阳能高精度拉压力传感器，通过 LoRaWAN 协议高频将箱内实时温湿度、物理总重量推送至后台。
*   **核心遥测指标解释**：
    1.  **实测箱体重量**：网关以寄存器数据读取实测总重量值，乘以 `0.01` 缩放因子后，在 Odoo 界面渲染出高精度的公斤数（例如：45.82 kg，重量稳步上升代表花蜜储量增加，重量骤降代表发生了分蜂飞逃）。
    2.  **箱内空气湿度**：网关读取实测箱内相对湿度。
    3.  **分蜂自愈警报**：当检测到蜂箱重量在 5 分钟内突然骤降超过 `3.0 kg`，系统会自动拉起分蜂警报。

### 2i.2.2 蜂箱重量遥测数据包格式 (HTTP IoT Telemetry Payload)

当传感器因外界温度波动或电量低上报异常时，网关会自动向系统的 API 发送状态明文报文。报文内容包括传感器名称（如：椴树蜜2号移动蜂箱）、时间戳、MAC地址、信号强度，以及物理检测指标：箱体重量、箱内空气温度、箱内相对湿度、电池剩余电压以及信号噪声比。

Odoo 接收到报文后，会自动将重量累计值写入蜂箱资产，并绘制折线图展示日增蜜重。

## 2i.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

蜂场安全的底线是防止含有药物残留（如螨药残留）或严重疫病（如美洲幼虫腐臭病）的蜂群进行采蜜及摇蜜。系统设立了“蜂群退化率与疫病指标 RLS 排他锁定”网关。

### 2i.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：场长在 Odoo“参数配置”中，设定蜂场允许的最大单箱蜂群退化率上限（默认值为 `15.00%`），以及药物残检测红线。
2.  **日常检疫**：疫病防治员定期开箱巡检，在 Odoo 中建立蜂箱检疫单，录入实测药物残留及蜂群活力衰退度。
3.  **安全判定**：
    *   **绿色状态（无感放行）**：检测药物残留为 0 且退化率低于 `15.00%`。系统在后台为该蜂箱颁发“摇蜜合规证”，允许创建后续的“摇蜜任务（Mission）”。
    *   **红色拦截（行级锁死阻断）**：若任何一项药物残留检出，或退化率突破 `15.00%` 警戒红线，系统触发强制拦截。

### 2i.3.2 疫病严重超标强拦截与物理隔离规程 (GxP Disease Gate SOP)

1.  **提交蜂箱检疫单**：当防治员建立“蜂群检疫不合规单”并点击“验证”时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该蜂群批次记录执行 `SELECT FOR UPDATE` 行级锁定，防止并发修改检疫数据，阻断采收摇蜜任务单的开具。
3.  **自动检索实时疫病健康历史**：
    *   系统检索本蜂群关联的所有质检单记录。
4.  **触发红色安全阀硬锁**：
    *   若不满足安全红线，系统强制抛出“蜂群药物残留超标或退化度突破安全红线”安全合规警告。
    *   异常将直接在采蜜员手持终端上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许出库或转入摇蜜车间的物料出库调拨单。
    *   **设备物理自愈动作**：系统自动将对应蜂箱的状态变更为“不合规检疫隔离”，向蜂箱防分蜂通道继电器下发指令关闭出口，并自动拉起自愈警报，启动物理土地客土净化和排水阻断自愈流程。

蜂蜜收割摇蜜属于典型的 **N:1 拼箱（Blending）**特征（多口蜂箱的原蜜，在摇蜜机摇出后汇入同一不锈钢储蜜桶中）。

### 2i.4.2 摇蜜拼箱谱系溯源数据报送规程 (Honey Blending Traceability SOP)

*   **摇蜜混合物料配平核算流程 (Silo Blending Calculation)**：
    当不同蜂箱的原蜜在不锈钢摇蜜机中混合时，Odoo 溯源引擎根据称重传感器上报的各箱采蜜净重，自动执行 N:1 混合物料核算。
*   **混合溯源报文格式明细 (Pedigree Breakdown)**：
    系统自动导出一份混合追溯报文。报文内容包括：目标储蜜桶的物理物料代号（LPN）、产品物理商品类型（例如：高品质长白山熟蜜）、混合日期与时间、以及混合后的总重量。
*   **加权品质指标与 Scope 1 排碳分摊 (Weighted Metrics & Scope 1 Allocation)**：
    报文精确拆解了每一路源头蜂箱的贡献详情：包括蜂箱 RFID 唯一码、贡献的分净重、在储蜜罐中所占的混合比例、历史箱温最大偏差、历史箱湿、以及自动分摊的 Scope 1 采蜜排碳。上述数据生成后将通过 API 自动加密上报，确保蜂蜜产品能实现全过程、可信、无缝的合规审计。
*   **一瓶一码可信溯源证书展现**：
    摇蜜罐装出厂后，操作员扫描包装箱。系统自动生成每瓶蜂蜜唯一的二维码标签。超市消费者手机扫码，即可无缝展现从手持蜂蜜瓶 -> 罐装厂 -> 储蜜桶摇蜜时间 -> 蜂箱日重传感器历史折线 -> 直至长白山林下 03 号蜜源地理标志 PostGIS 边界的完整自然生态链、理化检测与无残合规日志，确保道地高端长白山蜂蜜的高贵品质。

## 2i.5 异常排查与常见自愈 (Troubleshooting)

精准养蜂运行期间，传感器失联、分蜂飞逃及继电器卡死排除矩阵如下：

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-BEE-001** | 重量称重传感器长时间读取值为 0 | 称重传感器引脚接线松动、受潮短路或应变片严重损坏。 | 清洁称重传感器底部排污孔；检查应变片线圈阻值，使用手持终端校准零点。 |
| **ERR-BEE-002** | 检疫页面提示 “PEST_DETECTED” 警告 | 检测到蜂群美洲幼虫腐臭病或螨药超标，事务回滚。 | 锁定地块物料出库，物理隔离当前批次，向移动通道下发 0（保持关闭）信号，并自动启动物理客土治理。 |
| **ERR-BEE-003** | 蜂箱边缘网关上报 “LORA_LOW_VOLTAGE” | 蜂箱部署在深林密叶遮挡区，太阳能板长时间无法充电，电压低于 2.7V。 | 更换更大容量的移动锂电池组件，或将太阳能板物理向上延伸出灌木丛遮挡。 |

### 📐 物理数学计算模型：蜂群健康活力指数与蜂蜜采收预估

Agri-OS 在智能蜂业养殖中采用以下遥测评估模型：

1. **蜂箱健康活力度 (Colony Vitality Index - CVI)**:
   [ Vitality_Index ] = [ Flight_activity_count (ticks/min) ] * 0.6 + [ Humidity_stability_coeff ] * 0.4
   *   通过蜂箱门口的红外光电计数器，高频统计蜜蜂进出频次（ticks）。

2. **恒温控制系数 (Thermal Stability Coefficient)**:
   [ Thermal_Stability ] = 1.0 - SD( [ Internal_temp_24h ] ) / AVERAGE( [ Internal_temp_24h ] )
   *   健康的蜜蜂能将育雏区温度恒定在 34-35°C 之间，标准差（SD）越低则蜂群活力越强。
