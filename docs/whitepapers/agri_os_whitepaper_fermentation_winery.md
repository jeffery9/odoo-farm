## 2l.1 基础设置与发酵登记 (Setup & Registration)

发酵与酿造业务基于精密的发酵罐设备状态控制和科学的糖度/酒精度过程管理。系统通过 `farm_fermentation` 模块管理发酵罐资产、发酵试验/生产批次及转罐物理配方。

### 2l.1.1 发酵罐设备与发酵周期建立业务规程 (Fermentation Setup SOP)

*   **建立发酵罐（Fermenter）物理台账**：
    1.  登录系统，导航至“发酵管理 -> 发酵设备登记”菜单，系统触发唯一性档案初始化事务（Transaction Initialization）。
    2.  输入唯一的发酵罐物理编码（例如：FMT-TANK-04）。
    3.  输入直观的发酵罐名称（例如：精酿车间一号 10 吨不锈钢控温发酵罐）。
    4.  指定发酵罐设计的“最大工作容积（升）”（例如：10000.0 升）。
    5.  关联发酵罐配备的“物理控温夹套阀门”（例如：一号变频电磁控温阀）。
    6.  点击“保存”，系统会自动创建发酵罐设备档案，并初始化状态为“空闲”。

*   **初始化发酵试验周期批次**：
    1.  导航至“发酵周期”菜单并点击“新建”。
    2.  输入周期批次名称（例如：2026年夏季红红茶菌发酵/酿造试验批次）。
    3.  指定发酵的“物料/菌种配方”（detailed_type，例如：高活性红茶菌母液种子批）。
    4.  输入发酵设计的“初始糖度糖度（Brix）期望”（例如：12.5 Brix）。
    5.  关联绑定对应的物理发酵罐及原料罐批次。
    6.  点击“保存”，系统会自动调流水号发生器，在界面顶部生成唯一的发酵周期号（例如：FTC-2026-0008），并将当前状态初始化为“草稿”。

### 2l.1.2 界面操作与布局说明 (UI Layout & Interaction)

*   **列表视图（List View）**：
    在发酵周期列表视图下，展示发酵周期号、发酵名称、发酵罐、初始糖度、当前实测糖度、当前罐压（bar）及当前状态。利用 Odoo 19 原生行样式装饰器，数据行将根据状态自适应着色。草稿状态以淡蓝色气泡显示，“发酵中（Fermenting）”状态以绿色成功样式高亮标记，主发酵结束转罐或已完工（Done）状态显示为灰色。
*   **状态机推进与安全参数校验（State Machine & Controls）**：
    表单顶部设计有动作控制按钮和进度状态。发酵周期状态机包括“草稿”、“发酵中”、“后熟陈化中”、“已完工”。点击“启动发酵”时，系统验证当前发酵罐的 CIP 清洗历史是否处于“清洗完成合格”状态，通过后状态推进为“发酵中”。
*   **字段只读控制（Read-only Constraints）**：
    为了保证工艺数据的严谨性，一旦发酵周期进入“发酵中”状态，菌种配方、初始糖度、发酵罐关联等核心物理属性变更为只读状态，Chatter 会高频记录每一次工艺巡检和环境遥测历史。

## 2l.2 物联网架构与遥测闭环 (IoT & Telemetry Loop)

发酵期间的温度、罐内压力、pH 及折光糖度，通过防爆工业传感器及变频 PLC 电磁阀执行高频数据遥测与温控自愈调节。

### 2l.2.1 发酵罐环境 PLC 通信 SOP (Fermenter Modbus IoT SOP)

*   **PLC 通信网关轮询规程**：
    安装在发酵罐上的卫生级温湿度计、数字压力表、在线折光糖度仪，通过 Modbus TCP 协议将参数实时推送至 Odoo 后台时序表。
*   **核心遥测指标解释**：
    1.  **实测糖度（Brix）**：网关以寄存器数据读取实测糖度值，乘以 `0.1` 缩放因子后，在 Odoo 界面渲染出高精度的折光度（例如：11.2 Brix，发酵进行中该数值应持续下降）。
    2.  **实测罐体压力**：网关读取实测压力寄存器，乘以 `0.01` 缩放因子后在系统界面显示为 bar（例如：1.85 bar，若气压过高可能引发物理爆炸）。
    3.  **夹套冷却电磁阀开度**：网关读取冷却夹套比例调节阀状态（例如：45% 开度）。当发酵罐内部温度因微生物产热急剧上升时，PLC 网关会自动下发 1 指令调大电磁阀，调大冰水冷媒流量，自适应控制发酵温度曲线。

### 2l.2.2 发酵参数遥测数据包格式 (HTTP IoT Telemetry Payload)

当环境参数超出安全范围（例如糖度异常不下降或气压过高）时，网关会自动向系统的 API 推送包含设备编码、时间戳、物理检测指标：糖度（Brix）、罐体压力、pH 值、冷却水流量、电导率、以及安全泄压电磁阀状态等明文报文。

Odoo 接收到报文后，会将指标自动写入发酵周期时序记录，用于绘制折光率与酒精度变化曲线。

## 2l.3 业务拦截与 GxP 合规准入网关 (ORM Business Interception)

酿造车间的 GxP 重中之重是确保灌装前发酵罐进行完全的 CIP 无菌原位清洗且强碱性清洗剂（氢氧化钠）完全排净。系统设立了“清洗药剂残留超标自动行级排他锁定”网关。

### 2l.3.1 准入控制步骤 (SOP Setup)

1.  **设定阈值**：质量主管在 Odoo“参数配置”中，设定 CIP 清洗后强碱或酸性药剂残留（以 pH 偏移或电导率表征）的最高安全上限（例如：清洗水残留指标折合化学试剂浓度不得高于 `0.02 ppm`）。
2.  **验证拦截**：当灌装工尝试在 Odoo 中将本周期状态切换为“灌装释放（Bottling Release）”并点击“验证”时，系统启动自动审核。
3.  **安全判定**：
    *   **绿色状态（无感放行）**：当前实测清洗药残不高于 `0.02 ppm` 且最后一次 CIP 水洗合格。系统自动放行。
    *   **红色拦截（行级锁死阻断）**：若实测药残高于 `0.02 ppm`，系统触发强制拦截。

### 2l.3.2 药剂残留超标强拦截与物理隔离规程 (GxP CIP Gate SOP)

1.  **提交状态转换**：当灌装工点击“灌装释放”按钮时，系统启动底层检验。
2.  **数据库行锁锁定**：系统瞬间在数据库对该发酵周期记录执行 `SELECT FOR UPDATE NOWAIT` 行级排他锁锁定，阻止并发修改清洗化验数据，阻断灌装指令生成。
3.  **自动检索实时清洗药残**：
    *   系统检索本罐关联的所有时序清洗药残日志。
4.  **触发红色安全阀硬锁**：
    *   若发现实测强碱药残超标，系统强制抛出“CIP 清洗药残严重超标，残留试剂具有腐蚀性危险”安全合规警告。
    *   异常将直接在操作员手持终端上弹出高亮红色阻断框，强制回滚整个验证事务，不产生任何允许出炉或转入灌装车间的调拨凭证。
    *   **设备物理自愈动作**：系统自动向罐底排料气动阀门下发 0（保持关闭）信号，并启动主管道电磁阀反冲洗自愈。

### 2l.4.2 发酵转罐混匀谱系溯源数据报送规程 (Blending Traceability SOP)

*   **澄清混匀物料配平核算流程 (Silo Blending Calculation)**：
    当不同发酵罐的原液汇入澄清混匀罐时，Odoo 溯源引擎根据流量计传感器上报的各罐输入净重，自动执行 N:1 混合物料核算。
*   **混合溯源报文格式明细 (Pedigree Breakdown)**：
    系统自动导出一份混合追溯报文。报文内容包括：目标混匀罐的物理物料代号（Target Silo LPN）、产品物理商品类型（例如：发酵茶菌纯露）、混合日期与时间、以及混合后的总体积。
*   **加权品质指标与 Scope 1 排碳分摊 (Weighted Metrics & Scope 1 Allocation)**：
    报文精确拆解了每一路源头菌种和发酵周期的贡献详情：包括发酵周期号、贡献的液体体积、在混匀罐中所占的混合比例、历史发酵最大温差、发酵主气压最大值、以及自动分摊的 Scope 1 发酵过程总生产排碳。上述数据生成后将通过 API 自动加密上报，确保发酵企业能实现全过程、可追溯的高可信绿色合规审计。消费者扫描瓶身二维码，即可完美展现从零售瓶装 -> 灌装线 -> 混匀罐澄清时间 -> 各源头不锈钢发酵罐的温度压力历史曲线 -> 原料菌种谱系及原料采收批次，确保高端健康饮品的品牌信誉。

## 2l.5 异常排查与常见自愈 (Troubleshooting)

酿造设备运行期间，电磁阀卡死、气压过高及传感器通信故障排除矩阵如下：

| 错误代码 (Error Code) | 硬件/PLC 异常现象 (Symptom) | 根本原因 (Underlying Cause) | 排查及自愈步骤 (Remediation Step) |
| :--- | :--- | :--- | :--- |
| **ERR-FERM-001** | 发酵罐内压力（bar）迅速升高突破安全红线 | 气相排空手动阀未完全开启或物理安全阀泄压口被有机结焦杂质堵塞。 | 手动检查气相阀状态；手动机械拉起安全阀手柄进行泄压排空，清理阀门密封面有机结焦。 |
| **ERR-FERM-002** | 流程页面提示 “CIP_CHEMICAL_RESIDUE” 警告 | 化学残留高于 0.02 ppm 拦截红线，系统强制锁死调拨或灌装出口。 | 强制关闭出料阀，启动备用超纯水冲洗泵进行二次温水冲洗，直至电导率化验合格。 |
| **ERR-FERM-003** | 边缘网关上报 “MODBUS_RESPONSE_TIMEOUT” | 发酵罐防爆 PLC 控制箱与 Odoo HTTP 接口通信丢包或断开。 | 检查防爆网线水晶头阻抗，断电复位 Modbus 工业网关网卡以进行网络自愈。 |
